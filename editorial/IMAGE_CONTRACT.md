# WEEKLY SIGNAL 이미지 계약 — ARCHIVED / INACTIVE

> **현행 실행 계약이 아니다. 실행하지 않는다.**

이 파일은 Issue 02에서 진행했던 이미지 생성 파이프라인 실험의 역사적 기록 위치를 보존하기 위한 비활성 문서다.

## 현행 상태

- 상태: `ARCHIVED_INACTIVE`
- 현행 제작 경로: 이미지 생성 없는 5-페이즈 파이프라인
- 07:00 이미지 준비 작업: 없음
- 08:00 이미지 생성 작업: 없음
- `IMAGE_PLAN.md` 생성·갱신: 하지 않음
- `image_prompts/` 생성·전달: 하지 않음
- `jobs/image_job.json` 실행: 금지
- 이미지 확보 여부를 HTML 또는 발행 게이트로 사용: 금지

현재 실행 기준은 다음 문서가 소유한다.

1. `README.md`
2. `editorial/WEEKLY_RUNBOOK.md`
3. `editorial/ISSUE_QUALITY_GATE.md`
4. `editorial/LAYOUT_SYSTEM.md`
5. `editorial/PUBLISHING_PIPELINE.md`
6. 해당 회차 `work/YYYY-MM-DD/WORK_STATE.md`

## 역사적 맥락

Issue 02에서는 이미지 생성 과정에서 대화·저장소 운영 문맥이 장면 생성에 섞이는 `CONTEXT_FAILURE`가 반복되어 이미지 파이프라인을 현행 발행 경로에서 분리했다.

과거 v2/v2.1의 CONTROL PLANE, IMAGE PLANE, inline scene execution, queue, retry, persistence 규칙은 모두 현재 제작에서 비활성이다. 해당 개념을 발견해도 새 회차 작업에 적용하지 않는다.

## 향후 재도입 원칙

이미지 파이프라인을 다시 도입하려면 별도의 명시적 사용자 승인과 새 계약 버전이 필요하다. 그때까지 이 파일은 실행 지시가 아니라 과거 실험 기록으로만 취급한다.
