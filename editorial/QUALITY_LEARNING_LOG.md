# WEEKLY SIGNAL 품질 학습 기록

이 문서는 회차 수정 과정에서 얻은 판단을 다음 회차에 재사용하기 위한 영구 기록이다. 모델 자체가 Git 커밋을 보고 자동 학습하는 것은 아니다. 따라서 새 회차를 만들 때 이 문서와 `ISSUE_HISTORY.md`를 직접 읽고, 확인된 실패 원인과 합격 기준을 작업에 적용한다.

## 1. Issue 02 초판 실패 증거

- `archive/2026-07-27/index.html`이 약 19KB에 불과해 완성 매거진이 아니라 축소된 HTML 셸에 가까웠다.
- 표지·Cover Story·Economy·Politics·Society·Tech·LIFE SCENE 이미지 7개가 모두 동일한 4.9KB 파일이었다.
- 동일 이미지를 CSS의 색상 회전·채도·흑백 필터로 바꿔 서로 다른 이미지처럼 보이게 했다.
- Economy와 Politics가 독립 이슈를 다루지 않고 폭염 Cover Story를 분야명만 바꿔 반복했다.
- Society와 Tech는 공식 발표 한 건을 두세 문단으로 축약한 수준이었다.
- DEEP DIVE는 새 주장과 독립 근거가 없는 체크리스트형 확장에 머물렀다.
- 기사마다 제목 → 이미지 → 짧은 본문이라는 같은 구조를 반복했다.

## 2. 근본 원인

### 체크리스트 통과를 품질로 오인

기사 수와 섹션 이름을 채우는 데 집중하고, 각 기사가 독립적인 질문·자료·독자 가치를 갖는지는 충분히 검토하지 않았다.

### 억지로 하나의 주제에 묶음

호 전체의 통일성을 만들기 위해 Economy와 Politics까지 폭염으로 확장했다. 결과적으로 분야별 독립성이 사라지고 같은 인과가 반복됐다.

### 이미지 실패를 우회

적절한 이미지가 확보되지 않은 상태에서 동일 저용량 파일을 여러 이름으로 복제했다. 이미지가 없으면 발행을 멈춰야 했지만 CSS 필터로 우회했다.

### 템플릿 우선 제작

본문의 질문과 증거 구조보다 HTML 모듈을 먼저 정했다. 그래서 내용이 다른 기사도 같은 지면 리듬을 가졌다.

### 기술 검사가 편집 판단을 앞섬

파일 존재와 섹션 수는 확인했지만 원고의 깊이, 이미지 미감, 지면 완성도를 마지막까지 직접 비교하지 않았다.

## 3. Issue 02 교정에서 적용한 수정

- Cover Story는 폭염 경보 이후 기관별 운영체계와 실패 기록을 다룬다.
- DEEP DIVE는 일반 기사와 분리해 체감온도 33도, 2시간, 20분 휴식규칙의 측정·기록·비용·원청 책임을 분석한다.
- Economy는 석유 최고 공급가격의 정의, 비용 부담과 소비자가격 전달경로를 독립적으로 다룬다.
- Politics는 한·브라질 정상회담의 MOU와 한·메르코수르 협상의 현재 단계를 구분한다.
- Society는 야간·휴일 소아진료를 기관 수가 아닌 검색·전화·이동·접수·약국·전원 경로로 분석한다.
- Tech는 AMD 협력에서 GPU 수량보다 소프트웨어 이식, 이기종 운영과 전환비용을 분석한다.
- LIFE SCENE은 야간 소아진료 이용 과정에서 시간·이동·돌봄·정보 공백이 누적되는 생활 서사로 확장했다.
- EDITOR'S PICK은 기사별 요약을 버리고 ‘기관 수보다 이용 가능한 시간’으로 판단이 바뀐 한 지점만 썼다.
- 지면은 응답 사슬, 규칙 표, 가격 보드, 협상 상태 사다리, 서비스 여정, 기술 스택과 WATCH 보드로 분화했다.
- 동일 4.9KB 이미지 7회 복제를 제거하고 서로 다른 래스터 자산으로 분리했다.

## 4. 다음 회차에 적용할 영구 규칙

### 분야별 독립성

- Cover Story와 Economy·Politics·Society·Tech는 각각 다른 사건과 핵심 질문을 가져야 한다.
- 한 호의 통일성은 같은 주제 반복이 아니라 `발표를 실제 작동 조건으로 읽는다` 같은 편집 관점에서 만든다.
- 기사 제목의 분야명만 바꾸고 같은 원인·영향을 반복하면 탈락한다.

### 본문 우선

- 각 일반 기사는 디자인 없이 읽어도 충분한 설명과 분석을 가져야 한다.
- 공식 발표를 늘여 쓰지 말고 정의, 작동 구조, 책임, 비용, 반론, 다음 증거를 포함한다.
- Deck에 본문의 지식이 모두 들어가면 본문을 재조사한다.

### DEEP DIVE 차별성

- 일반 기사가 이미 답한 질문과 DEEP DIVE가 새로 답할 질문을 먼저 적는다.
- 새 핵심 주장 최소 3개와 독립 출처 최소 2개가 없으면 쓰지 않는다.
- 같은 원인 → 같은 경로 → 같은 결론이면 제목과 형식을 바꿔도 탈락한다.

### 이미지 무결성

- 기사별 주요 이미지 파일의 해시는 서로 달라야 한다.
- 동일 이미지를 색상·크롭·필터만 바꿔 재사용하지 않는다.
- 작은 파일을 여러 이름으로 복제하는 행위는 절대 금지한다.
- 이미지 생성 또는 로컬 저장에 실패하면 임시 그래픽으로 발행하지 않고 제작을 중단한다.
- 모든 이미지는 실제로 열어 디테일, 오류, 기사 적합성과 모바일 크롭을 확인한다.

### 내용 기반 지면

- 지면 모듈은 기사에 있는 실제 정보 구조에서 나온다.
- 숫자가 있으면 정의와 비교 기준을 보여주고, 절차가 있으면 상태·시간·책임 흐름을 보여준다.
- 장식용 카드와 본문 반복 모듈은 삭제한다.
- 모든 기사가 같은 제목·이미지·본문 패턴이면 탈락한다.

### LIFE SCENE

- 개인의 선택이나 주의가 아니라 제도·기관·서비스의 연결 실패를 보여준다.
- 대기·이동·비용·정보·일정·돌봄·책임 공백 중 최소 세 가지가 누적돼야 한다.
- 마지막 Scenario Note에서만 실제 정책과 연결한다.

### EDITOR'S PICK

- 모든 기사를 순서대로 요약하지 않는다.
- 실제 조사 중 판단이 바뀐 한 지점이나 오래 남은 사실 하나를 중심으로 쓴다.

### 상향 비교

- 새 회차는 제1호와 직전 회차를 나란히 비교한다.
- 원고 깊이, 이미지 디테일·차별성, 지면·모바일 읽기 경험 세 축에서 각각 개선점을 확인한다.
- 최소 조건 통과만으로 발행하지 않는다.

## 5. 이미지 교정의 한계

Issue 02의 첫 누적 교정에서는 동일 저용량 파일 복제를 즉시 제거하기 위해 기존 발행 래스터 자산 일부를 임시 재배치했다. 이는 최종 이미지 품질의 합격 사례가 아니다.

Issue 03부터는 다음을 발행 전제조건으로 적용한다.

- 회차별로 새로 생성한 로컬 래스터 이미지
- 기사마다 독립적인 장면·구도·조명
- 표지 장변 1800px 이상, 본문 주요 이미지 장변 1600px 이상
- 외부 URL이 아닌 회차 `assets/`의 실제 파일
- 육안 검수와 데스크톱·모바일 크롭 확인

## 6. 새 회차 시작 체크

1. `QUALITY_LEARNING_LOG.md`와 최근 `ISSUE_HISTORY.md`를 읽는다.
2. 직전 실패 패턴이 새 편성에 재등장하지 않는지 확인한다.
3. 분야별 후보를 최소 두 개 조사하고 독립 질문을 확정한다.
4. 본문을 완성한 뒤에만 이미지와 HTML을 만든다.
5. 이미지 파일 해시와 실제 화면을 직접 확인한다.
6. 직전 회차보다 나아진 세 가지를 기록한 뒤 `main`에 반영한다.
