# WEEKLY SIGNAL Issue 01 레이아웃 수치 명세

이 문서는 `archive/2026-07-20/index.html`의 최종 적용 상태를 기준으로 추출한 재현용 레이아웃 명세다. 1호의 결과물을 복사하는 것이 아니라, 실제로 유효했던 폭·간격·타이포그래피·반응형 수치를 다음 회차에서 재사용하기 위한 기준이다.

| 항목 | 실제 적용값 | 용도 |
