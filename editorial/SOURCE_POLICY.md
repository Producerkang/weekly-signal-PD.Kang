# WEEKLY SIGNAL Source Policy

이 문서는 WEEKLY SIGNAL의 조사·검증·출처 표기 기준이다.

> 저장소는 공개 상태다. 조사 노트에 사용자 개인 정보, 비공개 연락처, 계정 식별자, 로컬 파일 경로, 인증 정보 또는 사적인 대화를 기록하지 않는다.

## 1. 기본 원칙

1. 중요한 주장은 1차 자료를 기준으로 작성한다.
2. 발표·계획·계약·집행·성과를 서로 구분한다.
3. 수치에는 기준일, 단위, 범위와 성격을 확인한다.
4. 편집부의 추론은 사실과 분리해 표시한다.
5. 출처를 찾지 못한 구체적 사실은 쓰지 않는다.

## 2. 출처 우선순위

### 1순위 — 직접적인 1차 자료

- 법령, 시행령, 행정예고, 판결문, 국회 의안·회의록
- 정부·지방정부·공공기관의 공식 문서와 통계
- 중앙은행·통계기관·국제기구 자료
- 규제기관의 결정문·제재문·가이드라인
- 기업 공시, 감사보고서, 실적발표와 공식 기술문서
- 학술논문, 연구기관의 원자료와 방법론

### 2순위 — 맥락 보완 자료

- 주요 언론의 취재 기사
- 전문지의 산업 설명
- 신뢰할 수 있는 연구자·기관의 해설

2순위 자료는 사건의 맥락, 쟁점, 반론을 보완하는 데 사용한다. 핵심 수치와 법적 상태는 가능한 한 원문으로 다시 확인한다.

### 사용하지 않는 자료

- 출처 불명 블로그와 재가공 콘텐츠
- 개인 뉴스레터, 개인 SNS, 커뮤니티 게시물
- 유튜브·인플루언서 콘텐츠
- 광고성 기사와 협찬 콘텐츠
- 원문 링크 없이 숫자만 인용한 자료
- 생성형 AI가 제시한 출처를 원문 확인 없이 사용하는 행위

## 3. 한 기사에 필요한 근거

대표 기사에는 역할이 다른 1차 근거를 최소 3개 확보한다.

예시:

- 결정 또는 발표 원문
- 규모와 추세를 보여주는 통계
- 실제 집행 절차나 계약 조건을 보여주는 문서
- 영향을 받는 대상의 비용 또는 운영 조건을 보여주는 자료

하나의 기관이 낸 여러 보도자료가 같은 원문을 반복한다면 독립된 근거로 세지 않는다.

## 4. 주장 분류

원고 작성 전에 주요 주장을 다음 중 하나로 분류한다.

- **확정 사실**: 공식 문서로 직접 확인됨
- **발표·계획**: 향후 실행을 전제로 한 목표 또는 의향
- **계약·의무**: 구속력과 조건이 문서로 확인됨
- **집행 실적**: 실제 지출·착공·운영·처리 결과가 확인됨
- **추정·전망**: 모델·가정·기관 전망에 기반함
- **편집부 해석**: 여러 사실을 연결한 분석

본문에서 이 범주를 혼동하지 않는다. 특히 협력 총액, MOU, 목표 설비량은 실제 집행액이나 가동실적으로 쓰지 않는다.

## 5. 수치 검증

수치를 사용하기 전 다음을 확인한다.

- 발표일과 기준일
- 명목값과 실질값
- 원화·달러 등 통화와 환산 기준
- 누계·연간·분기·월간 여부
- 목표치·예산·계약액·집행액·매출의 차이
- 모집단, 표본, 조사 방식
- 이전 수치와 비교 가능한지 여부

비교 기준이 다르면 동일 선상에서 직접 증감률을 계산하지 않는다.

## 6. 상충하는 자료

공식 자료끼리 수치나 해석이 다를 경우:

1. 기준일과 정의 차이를 먼저 확인한다.
2. 최신 자료가 이전 수치를 수정했는지 확인한다.
3. 어느 한쪽을 임의로 선택하지 않는다.
4. 차이가 기사 판단에 중요하면 본문에서 불일치를 공개한다.
5. 해결되지 않으면 보수적인 표현을 사용하고 다음 검증 지점으로 남긴다.

## 7. 인용

직접 인용은 의미가 바뀌지 않는 최소 범위로 사용한다. 긴 문장을 인용해 권위를 빌리지 않는다.

- 인용 주체와 문서명을 표시한다.
- 번역한 경우 번역임을 명시한다.
- 발언과 공식 결정의 법적 효력을 구분한다.
- 익명 취재나 확인할 수 없는 발언을 만들지 않는다.

## 8. 링크와 출처 표기

각 대표 기사와 르포 끝에 주요 공식 출처를 배치한다.

출처 항목에는 다음을 포함한다.

- 기관명
- 문서 또는 발표 제목
- 날짜
- 원문 링크

링크가 변경될 수 있는 동적 페이지라면 문서 제목과 날짜를 정확히 남긴다. URL 추적 매개변수는 가능한 한 제거한다.

## 9. 리서치 기록

발행 과정의 공개 가능한 핵심 근거는 원고와 출처 지면에 남긴다. 임시 조사 메모는 저장소에 커밋하지 않는다.

로컬 조사 파일이 필요하면 다음 경로만 사용하고 Git 추적 대상에서 제외한다.

- `editorial/private/`
- `editorial/local/`
- `editorial/scratch/`

이 경로에도 비밀번호·토큰·개인 식별 정보는 저장하지 않는 것을 원칙으로 한다.

## 10. 개인 정보와 민감 정보

- 사용자 개인 정보는 기사 소재나 편집 문서에 사용하지 않는다.
- 실존 일반인의 연락처·주소·계정·건강·금융·가족 정보를 기록하지 않는다.
- 공개 직무와 직접 관련 없는 실존 인물의 사적 정보를 사용하지 않는다.
- 사례가 필요하면 공식 통계에 기반한 가상 인물로 재구성하고 가상임을 표시한다.
- 공개 문서에 개인 식별 정보가 포함되어 있어도 기사 목적에 불필요하면 삭제하거나 일반화한다.

## 11. 발행 전 출처 점검

- [ ] 모든 핵심 수치에 원문이 있는가
- [ ] 계획과 실적을 구분했는가
- [ ] 기사별로 역할이 다른 근거가 최소 3개인가
- [ ] 반론 또는 한계 자료를 확인했는가
- [ ] 편집부 해석이 사실처럼 쓰이지 않았는가
- [ ] 출처 링크가 열리는가
- [ ] 개인 정보와 비밀 정보가 포함되지 않았는가
