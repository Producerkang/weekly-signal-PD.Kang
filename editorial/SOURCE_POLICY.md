# WEEKLY SIGNAL Source Policy

이 문서는 WEEKLY SIGNAL의 조사·검증·출처 표기·정정 기준을 소유한다.

> 저장소는 공개 상태다. 조사 노트와 공개 문서에 사용자 개인 정보, 비공개 연락처, 계정 식별자, 로컬 절대경로, 인증 정보, API 키, 토큰, 쿠키 또는 사적인 대화를 기록하지 않는다.

## 1. 기본 원칙

1. 중요한 주장은 1차 자료를 기준으로 작성한다.
2. 발표·계획·계약·집행·성과를 서로 구분한다.
3. 수치에는 기준일, 단위, 범위와 성격을 확인한다.
4. 편집부의 추론은 사실과 분리해 표시한다.
5. 출처를 찾지 못한 구체적 사실은 쓰지 않는다.
6. 출처의 수보다 서로 다른 역할과 독립성을 우선한다.

## 2. 출처 우선순위

### 1순위 — 직접적인 1차 자료

- 법령, 시행령, 행정예고, 판결문, 국회 의안·회의록
- 정부·지방정부·공공기관의 공식 문서와 통계
- 중앙은행·통계기관·국제기구 자료
- 규제기관의 결정문·제재문·가이드라인
- 기업 공시, 감사보고서, 실적발표와 공식 기술문서
- 학술논문, 연구기관의 원자료와 방법론
- 계약서·입찰문서·운영 규정 등 공개된 원문

### 2순위 — 맥락 보완 자료

- 주요 언론의 취재 기사
- 전문지의 산업 설명
- 신뢰할 수 있는 연구자·기관의 해설

2순위 자료는 사건의 맥락, 영향과 반론을 보완하는 데 사용할 수 있다. 핵심 수치, 법적 상태, 계약 조건과 집행 실적은 가능한 한 원문으로 다시 확인한다.

### 일반 근거로 사용하지 않는 자료

- 출처 불명 블로그와 재가공 콘텐츠
- 개인 뉴스레터, 개인 SNS, 커뮤니티 게시물
- 유튜브·인플루언서 콘텐츠
- 광고성 기사와 협찬 콘텐츠
- 원문 링크 없이 숫자만 인용한 자료
- 생성형 AI가 제시한 출처를 원문 확인 없이 사용하는 행위

공식 계정의 게시물·영상·발언 자체가 분석 대상이면 예외적으로 1차 자료가 될 수 있다. 작성 주체, 원본성, 게시 시점과 이후 수정 여부를 확인하고 게시물의 주장과 법적·행정적 효력을 구분한다.

## 3. 기사별 근거 요건

일반 기사와 DEEP DIVE에는 다음 역할을 검토한다.

| 역할 | 확인할 자료 |
|---|---|
| 사건 | 결정·발표·판결·공시 원문 |
| 수치 | 규모·추세·비교를 보여주는 자료 |
| 구조 | 실제 집행·계약·행정 또는 운영 구조 |
| 영향 | 비용·권한·시간·접근성 변화 |
| 반론 | 제약·예외·불확실성 또는 다른 관점 |

원칙:

- 핵심 장문 기사에는 독립된 1차 자료를 원칙적으로 최소 3개 확보한다.
- 한 자료가 여러 역할을 뒷받침할 수 있지만 독립 근거 수에서는 한 번만 센다.
- 영향과 반론은 신뢰할 수 있는 2차 자료로 보완할 수 있다.
- 사건의 법적 상태, 핵심 수치와 집행 여부는 1차 자료로 확인한다.
- 같은 기관이 낸 여러 보도자료가 같은 원문을 반복하면 독립 자료로 세지 않는다.
- 기사 결론에 필수적인 근거 역할이 비면 장문을 시작하지 않고 범위를 줄인다.

DEEP DIVE는 일반 기사와 같은 자료만 재배열하지 않는다. 추가 반론·연구·비교 사례·과거 결과·시나리오 조건을 확인해 실제 지식 차이를 만든다.

LIFE SCENE의 가상 인물과 사건은 출처 대상이 아니다. 다만 마지막 `SCENARIO NOTE`에서 연결하는 실제 문제 구조와 정책은 공식 자료로 확인한다.

## 4. 주장 분류

원고 작성 전에 주요 주장을 다음 중 하나로 분류한다.

- **확정 사실**: 공식 문서로 직접 확인됨
- **발표·계획**: 향후 실행을 전제로 한 목표 또는 의향
- **법적·행정적 결정**: 효력과 결정 주체가 문서로 확인됨
- **계약·의무**: 구속력과 조건이 문서로 확인됨
- **집행 실적**: 실제 지출·착공·운영·처리 결과가 확인됨
- **성과·통계**: 정해진 기준과 방법으로 결과가 집계됨
- **추정·전망**: 모델·가정·기관 전망에 기반함
- **편집부 해석**: 여러 사실을 연결한 분석

협력 총액, MOU, 목표 설비량과 예산은 실제 집행액·가동실적·성과로 쓰지 않는다.

## 5. Claim Ledger

기사별 주요 주장은 발행 전 임시 Claim Ledger로 관리한다. 저장소에 조사 메모 전체를 커밋하지 않으며, 공개 기사에는 필요한 검증 결과와 공식 출처만 남긴다.

권장 필드:

- claim ID
- 기사와 문단
- 주장 요약
- 주장 분류
- 근거 역할
- 기관
- 문서명
- 발표일
- 자료 기준일
- 원문 URL
- 문서 내 위치 또는 표·쪽
- 상충 여부
- 최종 확인일
- 원고 반영 상태

Claim Ledger에 비공개 연락처, 계정 정보, 개인 식별 정보와 로컬 절대경로를 넣지 않는다.

## 6. 수치 검증

수치를 사용하기 전 다음을 확인한다.

- 발표일과 기준일
- 명목값과 실질값
- 원화·달러 등 통화와 환산 기준
- 누계·연간·분기·월간 여부
- 목표치·예산·계약액·집행액·매출·성과의 차이
- 모집단, 표본과 조사 방식
- 이전 수치와 비교 가능한지 여부
- 수정치·잠정치·확정치 여부

비교 기준이 다르면 동일 선상에서 직접 증감률을 계산하지 않는다.

## 7. 상충하는 자료

공식 자료끼리 수치나 해석이 다를 경우:

1. 기준일, 정의와 모집단 차이를 확인한다.
2. 최신 자료가 이전 수치를 수정했는지 확인한다.
3. 어느 한쪽을 임의로 선택하지 않는다.
4. 차이가 기사 판단에 중요하면 본문에서 불일치를 공개한다.
5. 해결되지 않으면 보수적인 표현을 사용하고 다음 검증 지점으로 남긴다.

## 8. 인용과 번역

- 직접 인용은 의미가 바뀌지 않는 최소 범위로 사용한다.
- 인용 주체와 문서명을 표시한다.
- 번역한 경우 번역임을 명시한다.
- 발언과 공식 결정의 법적 효력을 구분한다.
- 익명 취재나 확인할 수 없는 발언을 만들지 않는다.
- 긴 문장을 인용해 권위를 빌리지 않는다.

## 9. 링크와 출처 표기

각 일반 기사와 DEEP DIVE 끝에는 해당 글에 직접 사용한 주요 공식 출처를 배치한다. LIFE SCENE은 `SCENARIO NOTE` 또는 인접 출처 영역에서 실제 문제 구조와 정책 연결에 사용한 자료를 표시할 수 있다.

출처 항목에는 다음을 포함한다.

- 기관명
- 문서 또는 발표 제목
- 날짜
- 원문 링크

링크가 변경될 수 있는 동적 페이지라면 문서 제목, 날짜와 식별 가능한 정보를 정확히 남긴다. URL 추적 매개변수는 가능한 한 제거한다.

## 10. 발행 후 수정·정정

발행 후 원문이 수정·철회되거나 중요한 새 자료가 확인되면 다음 순서로 처리한다.

1. 변경된 원문과 이전 기사 주장의 관계를 확인한다.
2. 단순 링크 변경이면 출처 링크를 복구한다.
3. 수치·법적 상태·결론이 달라지면 기사 본문과 검증 메모를 수정한다.
4. 의미 있는 정정은 기사 후단 또는 Sources에 정정일과 변경 요지를 남긴다.
5. `latest.json`이나 과월호 경로를 임의로 바꾸어 정정을 숨기지 않는다.
6. 비밀정보가 노출된 경우 일반 정정이 아니라 이력 제거 절차를 우선한다.

## 11. 리서치 기록

발행 과정의 공개 가능한 핵심 근거는 원고와 출처 지면에 남긴다. 임시 조사 메모는 저장소에 커밋하지 않는다.

로컬 조사 파일이 필요하면 Git 추적에서 제외된 다음 경로만 사용한다.

- `editorial/private/`
- `editorial/local/`
- `editorial/scratch/`

이 경로에도 비밀번호·토큰·개인 식별 정보는 저장하지 않는 것을 원칙으로 한다.

## 12. 개인 정보와 민감 정보

- 사용자 개인 정보는 기사 소재나 편집 문서에 사용하지 않는다.
- 실존 일반인의 연락처·주소·계정·건강·금융·가족 정보를 기록하지 않는다.
- 공개 직무와 직접 관련 없는 실존 인물의 사적 정보를 사용하지 않는다.
- 사례가 필요하면 공식 통계와 확인된 제도 구조에 기반한 가상·합성 사례로 재구성하고 이를 표시한다.
- 공개 문서에 개인 식별 정보가 포함되어 있어도 기사 목적에 불필요하면 삭제하거나 일반화한다.

## 13. 발행 전 출처 점검

- [ ] 핵심 주장마다 Claim Ledger 근거가 있는가
- [ ] 사건·수치·구조·영향·반론 역할을 검토했는가
- [ ] 필요한 독립 1차 자료를 확보했는가
- [ ] 계획·결정·계약·집행·성과를 구분했는가
- [ ] 수치의 단위·기준일·모집단·성격이 확인됐는가
- [ ] 상충 자료를 임의로 누락하지 않았는가
- [ ] 편집부 해석이 사실처럼 쓰이지 않았는가
- [ ] DEEP DIVE의 추가 근거가 일반 기사와 실제 차이를 만드는가
- [ ] LIFE SCENE의 정책 연결이 공식 자료에 근거하는가
- [ ] 출처 링크가 열리고 원문 식별 정보가 남아 있는가
- [ ] 개인 정보와 비밀 정보가 포함되지 않았는가
