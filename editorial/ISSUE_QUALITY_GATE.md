# WEEKLY SIGNAL 회차 품질 게이트

이 문서는 수동 발행 차단 기준이다. GitHub Actions는 사용하지 않는다. 구조 검사 스크립트는 보조 수단이며, 최종 통과 여부는 제작자가 원고·이미지·지면·실제 화면을 직접 검수해 결정한다.

## 1. 기본 구성 게이트

별도 사용자 지시가 없는 한 한 호의 기본 구성은 다음과 같다.

1. Cover Story 1편
2. Economy 일반 기사 1편
3. Politics 일반 기사 1편
4. Society 일반 기사 1편
5. Tech 일반 기사 1편
6. DEEP DIVE 1~2편
7. LIFE SCENE 1편
8. PROLOGUE 1편
9. EDITOR'S AFTERWORD 1편
10. Sources

`EDITOR'S PICK`은 폐기된 레거시 섹션이다.

Cover Story는 분야 일반 기사를 대체하지 않는다. DATA와 WATCH도 일반 기사 대체물이 아니다.

## 2. 일반 기사 완성도 게이트

각 일반 기사는 최소한 다음 질문에 답해야 한다.

- 무슨 일이 있었는가
- 핵심 용어와 현재 상태는 무엇인가
- 기존과 무엇이 달라졌는가
- 실제로 어떤 절차·권한·돈·데이터가 움직이는가
- 누구에게 어떤 영향이 생기는가
- 가장 강한 반론이나 한계는 무엇인가
- 이후 어떤 문서·수치·사건이 판단을 바꾸는가

다음 징후가 있으면 재작성한다.

- 소제목과 문단 길이가 기계적으로 반복됨
- 정의와 사건 요약 뒤 곧바로 `관건`, `지켜봐야 한다`로 끝남
- 구체적인 책임 주체·기한·예산·문서·판단 지표가 없음
- Deck에 본문의 지식이 거의 모두 들어 있음
- 같은 인과를 표현만 바꿔 반복함

## 3. DEEP DIVE 차별성 게이트

필수 확인:

- 일반 기사가 이미 답한 질문
- DEEP DIVE가 새로 답할 단 하나의 질문
- 새 핵심 주장 최소 3개
- 일반 기사에 없던 독립 출처 최소 2개
- 선택한 심화 방식과 이유

다음은 탈락한다.

- 같은 원인 → 같은 경로 → 같은 결론
- 제목만 바꾼 연장 본문
- 일반 기사 소제목을 길게 반복
- 새 정보 없이 표나 카드만 추가

## 4. LIFE SCENE 게이트

LIFE SCENE은 제도·기관·서비스·절차의 문제가 개인의 생활에서 어떻게 체감되는지를 가상의 한 인물과 하나의 사건으로 보여준다.

필수:

- `SCENE_MAP.md` 선행
- 원래 계획 → 장애 → 행동 → 직접 결과 → 다음 선택의 인과 사슬
- 시간·장소·행동이 전진하는 서사
- 마지막 `SCENARIO NOTE`에서 가상 범위와 실제 사실 구분

다음은 탈락한다.

- 개인 조언으로 끝남
- 정책 설명이 서사를 압도함
- 실제 취재 사례처럼 보이게 만든 허구
- 생활 마찰을 체크리스트처럼 배치함

## 5. PROLOGUE 게이트

PROLOGUE는 한 호의 지면을 넓게 열었다가 몇 군데로 시선을 좁히고 본문으로 넘기는 매거진 도입부다.

필수:

- `PREVIEW_MAP.md` 선행
- `넓게 → 좁게 → 본문`의 시선 이동
- 본문 결론과 핵심 메커니즘을 미리 소진하지 않음
- 선택 기사 미니 초록 모음으로 변하지 않음
- PANORAMA의 넓은 커버리지를 뒤에서 다시 전부 반복하지 않음

## 6. EDITOR'S AFTERWORD 게이트

EDITOR'S AFTERWORD는 모든 기사와 DEEP DIVE 뒤, Sources 직전에 읽는 실제 에디터 후기다.

통과 조건:

- 제작 후 시점이 자연스럽다.
- 기사 요약보다 실제 회고가 앞에 있다.
- 대표 기사·대표 숫자·대표 문장을 억지로 하나 고르지 않는다.
- 모든 기사를 하나의 공통 교훈으로 묶지 않는다.
- 내부 VERIFY·FLOW·검수 방법론 보고서가 아니다.
- 끝을 질문·감사·다음 호 예고로 의무적으로 닫지 않는다.

## 7. 이미지 품질 게이트

이미지 관련 세부 규칙은 **`editorial/IMAGE_CONTRACT.md` 하나만** 기준으로 한다.

발행 전 REQUIRED 이미지마다 다음을 확인한다.

### 7.1 산출물

- 프레임 전체가 하나의 독립된 사진적 에디토리얼 장면인가
- 기사 지면에 직접 삽입 가능한가
- 텍스트·UI·문서 구조가 이미지의 주된 형태가 아닌가

위 조건을 통과하지 못하면 `NON_SCENE_OUTPUT` 실패다.

### 7.2 시각 품질

- 기사 주제와 자연스럽게 연결됨
- 중심 장면이 명확함
- 재질·공간·조명·원근이 자연스러움
- 눈에 띄는 생성 오류가 없음
- 실제 지면 크롭이 가능함

기사의 모든 메커니즘을 이미지 한 장에 설명할 필요는 없다.

합격권 이미지는 취향상 더 좋은 결과를 찾기 위해 반복 생성하지 않는다.

### 7.3 해상도

새 생성 목표:

- Cover 장변 2200px 이상
- 나머지 주요 이미지 장변 2000px 이상

원본이 목표보다 약간 낮더라도 실제 지면에서 충분히 선명하면 편집 판단으로 사용할 수 있다. 단순 확대만으로 규격을 맞추지 않는다.

### 7.4 LIFE SCENE

LIFE SCENE은 회차 지면에서 가로 `4:3` 또는 세로 `4:5` 중 하나를 확정한다.

### 7.5 Politics

Politics와 Politics DEEP DIVE는 완전 무인이다.

프레임 안 어디에도 사람, 얼굴, 실루엣, 손·신체 일부가 없어야 하며 반사면·화면·사진 속 인물도 허용하지 않는다.

### 7.6 재사용과 오류

- 다른 기사와 동일한 원본 재사용 금지
- 지면을 방해하는 의미 없는 큰 글자·로고·워터마크 금지
- 눈에 띄는 인체·장비·공간 구조 오류 금지

### 7.7 재시도

한 슬롯은 기본 최대 3회의 유효 이미지 시도까지 진행한다.

세 번의 유효 시도에서도 실패하면 `BLOCKED`로 기록하고 다른 슬롯 작업을 계속한다.

기사 이미지 자체가 아닌 `NON_SCENE_OUTPUT`은 유효 품질 시도로 계산하지 않는다.

## 8. 잡지 지면 게이트

`templates/ISSUE_TEMPLATE.html`은 DOM 시작점일 뿐 완성 디자인이 아니다.

한 호에는 최소 세 가지 이상의 서로 다른 기사 지면 리듬이 있어야 한다.

확인:

- LIFE SCENE → PROLOGUE → 본 기사 진입이 자연스러운가
- 기사별 이미지·정보 모듈·여백의 리듬이 실제로 다른가
- 장식 모듈이 본문을 반복하지 않는가
- EDITOR'S AFTERWORD → Sources가 자연스럽게 닫히는가
- 1440px, 1366px, 1024px, 390px에서 문제가 없는가

## 9. 실제 화면 게이트

HTML 코드만 보고 통과시키지 않는다.

반드시 실제 화면에서 다음을 확인한다.

- 이미지가 독립 기사 이미지로 정상 표시되는지
- 이미지 크롭과 선명도
- 제목 오버플로
- 표·카드·타임라인 반응형
- 내비게이션·Contents·DOM 순서 일치
- 모바일 가로 스크롤 여부
- Politics 이미지 무인 여부
- 링크와 상대경로

이미지 크롭 문제는 먼저 CSS `object-position`과 지면 비율로 해결하고, 이미지 자체가 근본적으로 잘못된 경우에만 재생성한다.

## 10. 발행 차단

다음 상태에서는 발행하지 않는다.

- 기본 기사 누락
- 원고 품질 게이트 실패
- DEEP DIVE 중복
- LIFE SCENE 서사 실패
- PROLOGUE 또는 AFTERWORD 역할 실패
- REQUIRED 이미지 미확보
- REQUIRED 이미지가 이미지 품질 게이트를 통과하지 못함
- Politics 이미지에 사람 등장
- 실제 화면 미검수

자동 검사 통과는 발행 승인과 동일하지 않다.
