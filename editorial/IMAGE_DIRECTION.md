# WEEKLY SIGNAL 이미지 방향

이 문서는 제2호 이후 표지, 일반 기사, DEEP DIVE와 LIFE SCENE에 사용하는 이미지 기준을 규정한다.

## 1. 절대 원칙

모든 주요 이미지는 회차별로 새로 제작한 **래스터 생성 이미지**를 사용한다.

금지:

- SVG 및 벡터 파일
- 플랫 벡터 일러스트
- 아이콘 콜라주
- 아이소메트릭 이미지
- 인포그래픽풍 장식 이미지
- 외부 스톡 사진과 보도사진 직접 사용
- 웹페이지·잡지 지면 전체를 이미지로 생성하는 방식

허용 래스터 형식은 WebP, PNG, JPEG이다. 기본값은 용량과 품질을 균형 있게 조정한 WebP로 한다.

## 2. 시각 방향

이미지는 기사를 도식으로 요약하지 않는다. 한 장면과 현실적인 공간·재질·빛을 통해 기사의 분위기와 문제를 체감하게 한다.

기본 방향:

- 세련되고 깨끗한 에디토리얼 생성 이미지
- 현실적인 카메라 시점과 조명
- 자연스러운 재질과 불완전성
- 하나의 중심 장면
- 과도한 광고·기업 홍보·게임 콘셉트 배제
- 이미지 내부 텍스트에 의존하지 않는 구성

## 3. 지면별 역할

### 표지

대표 기사의 긴장을 한 장면으로 압축한다. 강한 중심 피사체와 제목이 놓일 여백을 고려한다. 여러 상징물을 한 화면에 나열하지 않는다.

### 일반 기사

기사 내용이 실제로 존재할 법한 공간과 상황을 보여준다. 정책명이나 산업 용어를 아이콘으로 번역하지 않는다.

- Economy: 생산·거래·물류·업무 공간
- Politics: 공공 기록·권한·행정이 존재하는 현실적 공간
- Society: 생활 서비스·이동·대기·접근이 드러나는 장면
- Tech: 실제 장비·업무환경·데이터 인프라의 현실감

### DEEP DIVE

래스터 생성 이미지를 사용한다. 기사보다 더 추상적인 쟁점을 다루더라도 벡터 도식으로 대체하지 않는다. 비교·대립·구조를 시각화할 때도 하나의 에디토리얼 장면이나 래스터 콜라주로 표현한다.

실제 수치·관계·절차를 정확히 설명해야 하는 경우에는 생성 이미지가 아니라 HTML/CSS 기반 데이터 조판을 별도 사용한다. 이를 이미지 파일로 위장하지 않는다.

### LIFE SCENE

독자가 “나도 겪을 수 있겠다”고 느끼게 하는 현실적인 생활 장면을 만든다.

- 한국의 실제 생활 공간과 자연스러운 복장
- 과장되지 않은 표정과 행동
- 인물이 카메라를 의식하지 않는 구성
- 이야기의 한 결정적 순간
- 광고형 포즈, 과도한 비극, 감정 과장 금지

## 4. 프롬프트 원칙

프롬프트에는 다음을 포함한다.

1. 한 장면
2. 구체적인 공간과 시간대
3. 핵심 인물 또는 사물
4. 카메라 시점과 구도
5. 조명·재질·분위기
6. 사실 오인 방지 조건
7. 금지 요소

매번 다음 금지 방향을 명시한다.

- no text, letters, numbers, logo, watermark
- no webpage or magazine layout
- no infographic
- no vector art
- no flat illustration
- no icon collage
- no isometric illustration
- no synthetic corporate 3D object montage

생성 결과가 벡터풍·아이콘풍·인포그래픽풍이면 사용하지 않고 다시 생성한다.

## 5. 사실성·고지

- 생성 이미지는 사실 근거 또는 실제 현장 기록이 아니다.
- 실제 사건 현장·실존 인물·특정 기업 내부·정부 문서를 정확히 재현한 것처럼 만들지 않는다.
- 실제 사진으로 오인될 가능성이 있으면 캡션 또는 인접 설명에 `편집용 생성 이미지`를 표시한다.
- 이미지 안의 장면·장비·수치를 기사 근거로 인용하지 않는다.
- 사실 확인이 필요한 수치와 문서는 HTML 텍스트와 공식 출처로 제시한다.

## 6. 인물과 개인정보

- 실존 일반인을 재현하지 않는다.
- 특정인을 식별할 수 없는 가상 인물을 사용한다.
- 명찰·화면·문서·차량번호·기기에는 실제 이름, 이메일, 전화번호, 주소와 회사명이 보이지 않게 한다.
- 취약한 사람의 고통과 공포를 자극적으로 소비하지 않는다.

## 7. 파일 사양

- 경로: `archive/YYYY-MM-DD/assets/`
- 참조: `./assets/...` 상대경로
- 대표 이미지 권장 폭: 1600px 이상
- 모바일 크롭에서도 핵심 피사체가 남도록 안전영역 확보
- 불필요한 원본·중간 생성본·중복 파일은 커밋하지 않는다.
- SVG 파일은 회차 assets에 두지 않는다.

## 8. 접근성

의미 있는 이미지에는 기사 의미를 설명하는 간결한 대체 텍스트를 제공한다. `멋진 이미지`, `AI 이미지`처럼 정보가 없는 문구를 사용하지 않는다.

## 9. 발행 전 검사

- [ ] 래스터 파일인가
- [ ] SVG·벡터·플랫 일러스트·아이콘 콜라주가 아닌가
- [ ] 실제 카메라 공간감과 자연스러운 재질이 있는가
- [ ] 글자·숫자·로고·워터마크가 없는가
- [ ] 기사 또는 서사의 핵심과 직접 연결되는가
- [ ] 실제 현장으로 오인될 경우 생성 이미지 고지가 있는가
- [ ] 개인정보와 실존 일반인 식별 요소가 없는가
- [ ] 이전 이미지와 의미 없이 중복되지 않는가
- [ ] 데스크톱과 모바일 크롭에서 핵심 피사체가 남는가
- [ ] 대체 텍스트와 필요한 캡션이 있는가
