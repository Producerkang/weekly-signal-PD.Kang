# WEEKLY SIGNAL 이미지 방향

이 문서는 WEEKLY SIGNAL 주요 이미지의 **회차 독립적인 시각 품질과 표현 방향**을 규정한다.

실제 생성 순서·상태·재시도·저장·HTML 반영 절차는 `editorial/IMAGE_PIPELINE.md`가 소유한다. 특정 회차의 슬롯·파일명·비율 오버라이드·장면 브리프는 해당 회차의 `LAYOUT_PLAN.md`와 `IMAGE_PLAN.md`가 소유한다.

이미지 관련 다른 문서와 충돌하면 `IMAGE_PIPELINE.md`와 이 문서의 현행 규칙을 우선한다.

## 1. 기본 품질선

주요 이미지는 잡지 지면에서 안정적으로 사용할 수 있는 고품질 래스터 생성 이미지로 제작한다.

허용 형식:

- WebP
- PNG
- JPEG

목표는 초고난도 광고 비주얼이나 실제 보도사진의 완벽한 재현이 아니다.

통과 가능한 기본 품질은 다음과 같다.

- 현실적인 재질·빛·공간감이 있다.
- 중심 장면이 한눈에 읽힌다.
- 기사 주제와 자연스럽게 연결된다.
- 눈에 띄는 생성 오류가 없다.
- 실제 지면 크롭과 반응형 배치에 사용할 수 있다.

특정 과거 회차나 특정 시연 결과를 영구 품질 기준으로 삼지 않는다. 과거 발행본은 필요할 때 참고 사례로만 비교한다.

## 2. 기사와 이미지의 관계

이미지는 기사 내용을 문자 그대로 설명하는 도식이 아니다.

통과 기준:

- 기사 주제와 자연스럽게 연결된다.
- 독자가 분야와 핵심 소재를 잘못 이해하지 않는다.
- 지면에서 분위기·장면 전환·시각적 밀도 역할을 수행한다.

기사의 전체 메커니즘을 한 장 안에 재현하거나 모든 사실을 시각화할 필요는 없다.

## 3. 시각 방향

기본 방향:

- 현실적인 카메라 시점 또는 고품질 사진적 합성
- 자연스러운 재질·빛·공간감
- 한눈에 읽히는 중심 장면
- 기사별로 다른 공간·거리·구도
- 과도한 광고 포즈와 기업 홍보 이미지 배제
- 이미지 내부 텍스트에 의존하지 않는 구성

사진적 장면 위에 절제된 네트워크 선·빛·연결 효과가 더해지는 등 **상징적 에디토리얼 합성**은 허용한다. 다만 사실 수치·가격·단계·정책 관계를 이미지 내부 도표로 설명하지 않는다.

## 4. 표지

표지는 대표 기사와 자연스럽게 연결되는 강한 장면을 사용한다.

- 제목이 놓일 안전영역을 고려한다.
- Cover Story 본문 이미지와 같은 원본을 재사용하지 않는다.
- 같은 주제를 다루더라도 거리·구도·장면 역할을 달리할 수 있다.
- 장면이 꼭 실제 사건 현장을 재현할 필요는 없다.

## 5. 일반 기사

일반 기사 이미지는 기사 소재가 존재할 법한 공간·사물·행동을 자연스럽게 보여준다.

예시 방향:

- Economy: 생산·유통·거래·물류·노동·업무 공간
- Society: 생활 서비스·이동·대기·돌봄·접근 장면
- Tech: 장비·연구환경·서버·공정·데이터 인프라의 물리적 현실감

분야 클리셰를 기계적으로 반복하지 않고 해당 기사 주제와 연결되는 범위에서 자유롭게 선택한다.

## 6. Politics 절대 규칙

Politics와 Politics에 연결된 정치 DEEP DIVE의 생성 이미지는 **완전 무인(human-free)** 이어야 한다.

절대 금지:

- 사람
- 얼굴
- 실루엣
- 뒷모습
- 손 또는 신체 일부
- 원거리 인물
- 실제 정치인·공직자를 닮은 인물
- 정상회담·악수·기자회견 인물 재현

허용 방향:

- 빈 회의실
- 빈 협상 테이블
- 빈 연단·브리핑룸
- 문서·의자·마이크·공적 공간
- 항만·통관·행정 시설 등 사물과 장소 중심 장면

사람이 한 명이라도 보이면 즉시 탈락한다.

## 7. DEEP DIVE

DEEP DIVE는 일반 기사보다 추상적인 주제를 다뤄도 된다.

- 사진적 장면
- 실제 공간을 기반으로 한 에디토리얼 합성
- 사물과 환경 중심 이미지

를 사용할 수 있다.

정확한 관계·절차·수치는 HTML/CSS 기반 정보 조판으로 제공한다. 이미지가 없어도 지면 설계가 성립하면 DEEP DIVE 이미지는 생략할 수 있다.

## 8. LIFE SCENE

LIFE SCENE은 독자가 실제 생활의 한 순간처럼 느낄 수 있는 장면을 사용한다.

기본 방향:

- 한국의 자연스러운 생활 공간
- 평범한 복장과 행동
- 과장되지 않은 표정과 자세
- 인물이 카메라를 의식하지 않는 구성
- 이야기의 결정적 순간 하나
- 광고형 포즈와 과도한 비극 금지

### 기본 비율

LIFE SCENE은 **세로형 `4:5`를 기본값**으로 한다.

세로형은 인물과 생활 공간을 함께 담고, 한 장면에 시선을 머물게 하는 LIFE SCENE의 기본 성격에 적합하다.

다만 해당 회차의 실제 지면이 넓은 스프레드나 가로 장면을 요구하면 `LAYOUT_PLAN.md`와 `IMAGE_PLAN.md`에서 가로형 `4:3`으로 오버라이드할 수 있다.

- 기본: `4:5`
- 회차별 지면상 필요가 명확할 때: `4:3`

한 LIFE SCENE에 두 비율을 모두 의무 생성하지 않는다. 회차 계획에서 확정한 한 비율만 생성한다.

## 9. 해상도

새 생성의 목표 최소값:

- Cover: 장변 `2200px` 이상
- 그 외 주요 이미지: 장변 `2000px` 이상

LIFE SCENE도 동일한 해상도 원칙을 적용한다.

저해상도 결과를 단순 확대해 규격만 맞추지 않는다.

## 10. 생성 결과에서 피할 것

주요 기사 이미지로 다음 결과는 사용하지 않는다.

- 연락시트
- 이미지 팩
- 스토리보드
- 무드보드
- 잡지 페이지나 웹페이지 자체를 이미지로 생성한 결과
- 분할 패널
- 아이콘을 여러 개 나열한 인포그래픽
- 명백한 플랫 벡터·아이소메트릭 대체 이미지
- 저해상도 썸네일 확대본
- 다른 기사와 동일한 원본 재사용

반대로 사진적 장면에 절제된 합성 효과가 있다는 이유만으로 자동 탈락시키지 않는다.

## 11. 글자·숫자·로고

이미지는 텍스트에 의존하지 않는 방향을 기본으로 한다.

다음은 재생성 또는 폐기 대상이다.

- 크게 읽히는 의미 없는 글자
- 시선을 지배하는 숫자
- 실제 브랜드나 기관 로고처럼 보이는 요소
- 워터마크

다만 배경 깊숙한 곳의 흐릿하고 식별 불가능한 표식까지 기계적으로 탈락시키지 않는다. 최종 지면에서 실제 독서에 방해되는지가 기준이다.

## 12. 육안 검수

모든 최종 후보는 실제로 열어 확인한다.

- 기사 주제와 자연스럽게 연결되는가
- 중심 장면이 한눈에 읽히는가
- 얼굴·손·장비·반사면에 눈에 띄는 오류가 없는가
- 글자·숫자·로고가 시선을 방해하지 않는가
- 공간과 재질이 크게 어색하지 않은가
- 다른 기사 이미지와 동일하지 않은가
- Politics라면 사람이 완전히 없는가
- 지면 크롭에 사용할 수 있는가

완벽한 무결점보다 **실제 지면에서 충분히 자연스럽고 기능하는지**를 우선한다.

## 13. 사실성·고지

- 생성 이미지는 기사 근거나 실제 현장 기록이 아니다.
- 실제 사건 현장·실존 인물·특정 기관 내부를 정확히 재현한 것처럼 만들지 않는다.
- 실제 사진으로 오인될 가능성이 있으면 `편집용 생성 이미지`를 표시한다.
- 이미지 속 장면·장비·수치를 기사 근거로 사용하지 않는다.
- 사실 확인이 필요한 정보는 본문과 공식 출처에서 제시한다.

## 14. 개인정보와 인물

- 실존 일반인을 재현하지 않는다.
- 인물이 필요한 비정치 이미지에서는 식별할 수 없는 가상 인물을 사용한다.
- 명찰·화면·문서·차량번호 등에 실제 개인정보가 보이지 않게 한다.
- 취약한 사람의 고통을 자극적으로 소비하지 않는다.

## 15. 파일 관리

- 최종 경로: `archive/YYYY-MM-DD/assets/`
- 참조: `./assets/...`
- 최종 채택 이미지와 실제 발행 파일만 둔다.
- 실패본·중간 후보·연락시트는 `archive/`에 두지 않는다.
- 같은 SHA 또는 사실상 같은 이미지를 여러 기사에 사용하지 않는다.

## 16. 접근성

의미 있는 이미지에는 기사 의미를 설명하는 간결한 대체 텍스트를 제공한다.

`멋진 이미지`, `AI 이미지`처럼 정보가 없는 대체 텍스트는 사용하지 않는다.

## 17. 회차 독립성

이 문서에는 특정 회차의 다음 정보를 넣지 않는다.

- 실제 파일명
- 확정 슬롯 수
- 특정 기사 제목
- 특정 회차의 선택 비율
- 특정 장면 브리프
- 과거 회차 이미지의 품질을 영구 기준으로 삼는 표현

이 정보는 해당 회차의 `LAYOUT_PLAN.md` 또는 `IMAGE_PLAN.md`에서만 관리한다.

## 18. 실행 계약

이미지 한 장의 실제 제작 순서, 상태, 실패 유형, 최대 재시도 횟수, 저장 및 HTML 반영은 `editorial/IMAGE_PIPELINE.md`를 따른다.
