# WEEKLY SIGNAL 이미지 방향

이 문서는 표지, 일반 기사, DEEP DIVE와 LIFE SCENE의 이미지 제작·검수 기준을 규정한다.

## 1. 절대 원칙

모든 주요 이미지는 회차별로 실제 이미지 생성 모델을 사용해 새로 제작한 **고품질 래스터 생성 이미지**여야 한다.

허용 형식:

- WebP
- PNG
- JPEG

파일 형식이 래스터라는 사실만으로 통과시키지 않는다.

## 2. 절대 금지

- SVG 및 벡터 파일
- 플랫 벡터 일러스트
- 아이콘 콜라주
- 아이소메트릭 이미지
- 인포그래픽풍 장식 이미지
- 합성 기업용 3D 오브젝트 몽타주
- Python·Canvas·CSS·SVG·도형 조합으로 장면을 만든 뒤 래스터로 저장하는 방식
- 단색 그라디언트와 몇 개의 도형을 기사 이미지로 사용하는 방식
- 외부 스톡 사진과 보도사진 직접 사용
- 웹페이지·잡지 지면 전체를 이미지로 생성하는 방식
- 저해상도 썸네일 확대
- 동일 원본을 색상·크롭만 바꿔 여러 기사에 재사용
- 생성 실패를 임시 그래픽으로 대체한 채 발행

## 3. 시각 방향

이미지는 기사를 아이콘으로 요약하지 않는다. 한 장면과 현실적인 공간·재질·빛을 통해 기사 분위기와 문제를 체감하게 한다.

기본 방향:

- 세련되고 깨끗한 에디토리얼 생성 이미지
- 현실적인 카메라 시점과 조명
- 자연스러운 재질과 미세한 불완전성
- 하나의 중심 장면
- 기사별로 다른 장소·시간대·구도
- 과도한 광고·기업 홍보·게임 콘셉트 배제
- 이미지 내부 텍스트에 의존하지 않는 구성

`photorealistic`이라는 단어만 추가해 통과시키지 않는다. 실제 결과가 저디테일·벡터풍·3D 렌더풍이면 폐기하고 다시 생성한다.

## 4. 지면별 역할

### 표지

대표 기사의 긴장을 한 장면으로 압축한다. 강한 중심 피사체와 제목 안전영역을 확보한다. 여러 상징물을 한 화면에 나열하지 않는다.

표지와 Cover Story 본문 이미지는 서로 다른 장면 또는 명확히 다른 구도와 역할을 가져야 한다.

### 일반 기사

기사 내용이 실제로 존재할 법한 공간과 상황을 보여준다.

- Economy: 생산·거래·물류·노동·업무 공간
- Politics: 권한·기록·행정·공적 절차가 존재하는 공간
- Society: 생활 서비스·이동·대기·돌봄·접근 장면
- Tech: 실제 장비·업무환경·데이터 인프라의 물리적 현실감

정책명이나 산업 용어를 떠다니는 아이콘으로 번역하지 않는다.

### DEEP DIVE

기사보다 추상적인 쟁점이라도 벡터 도식으로 대체하지 않는다. 하나의 에디토리얼 장면 또는 실제 사진적 질감을 가진 래스터 콜라주를 사용한다.

정확한 수치·관계·절차는 HTML/CSS 기반 데이터 조판으로 제공한다. 생성 이미지 안에 사실 관계를 그려 넣지 않는다.

### LIFE SCENE

독자가 “나도 겪을 수 있겠다”고 느끼게 하는 현실적인 생활 장면을 만든다.

- 한국의 실제 생활 공간과 자연스러운 복장
- 과장되지 않은 표정과 행동
- 인물이 카메라를 의식하지 않는 구성
- 이야기의 결정적 순간 하나
- 광고형 포즈와 과도한 비극 금지

## 5. 프롬프트 구성

프롬프트에는 다음을 포함한다.

1. 한 장면
2. 구체적인 공간과 시간대
3. 핵심 인물 또는 사물
4. 카메라 시점과 렌즈 느낌
5. 조명·재질·분위기
6. 기사와 연결되는 행동 또는 긴장
7. 제목이 놓일 안전영역 여부
8. 사실 오인 방지 조건
9. 금지 요소

매번 다음 금지 방향을 명시한다.

- no text, letters, numbers, logo, watermark
- no webpage or magazine layout
- no infographic
- no vector art
- no flat illustration
- no icon collage
- no isometric illustration
- no synthetic corporate 3D object montage

## 6. 파일 품질 기준

- Cover 원본 장변 1800px 이상
- 일반 기사·DEEP DIVE·LIFE SCENE 원본 장변 1600px 이상
- WebP 권장 품질 88~94
- 모바일 크롭에서도 핵심 피사체가 남도록 안전영역 확보
- 생성 원본을 과도하게 축소·압축하지 않음
- 장변 1600px 이상인데 파일 크기가 80KB 미만이면 자동 탈락 후보로 분류하고 원본과 화면을 재검사

80KB 기준은 품질 보증이 아니라 비정상적으로 단순하거나 과압축된 이미지를 잡기 위한 경고선이다. 실제 육안 검사가 최종 기준이다.

## 7. 육안 검수

모든 주요 이미지를 실제로 열어 다음을 확인한다.

- 벡터·플랫·저디테일로 보이지 않는가
- 기사와 직접 연결되는 한 장면인가
- 얼굴·손·눈·장비·문서·반사면에 생성 오류가 없는가
- 글자·숫자·로고·워터마크가 없는가
- 재질과 공간 깊이가 자연스러운가
- 표지와 기사 이미지가 서로 다른 역할을 갖는가
- 이전 회차나 같은 회차의 다른 이미지와 의미 없이 중복되지 않는가
- 데스크톱과 모바일 크롭에서 핵심이 남는가

파일명, 해상도, 확장자만 확인하고 검수를 끝내지 않는다.

## 8. 사실성·고지

- 생성 이미지는 기사 근거나 실제 현장 기록이 아니다.
- 실제 사건 현장·실존 인물·특정 기업 내부·정부 문서를 정확히 재현한 것처럼 만들지 않는다.
- 실제 사진으로 오인될 가능성이 있으면 `편집용 생성 이미지`를 표시한다.
- 이미지 속 장면·장비·수치를 기사 근거로 인용하지 않는다.
- 사실 확인이 필요한 수치와 문서는 HTML 텍스트와 공식 출처로 제시한다.

## 9. 인물과 개인정보

- 실존 일반인을 재현하지 않는다.
- 식별할 수 없는 가상 인물을 사용한다.
- 명찰·화면·문서·차량번호·기기에 실제 이름, 이메일, 전화번호, 주소와 회사명이 보이지 않게 한다.
- 취약한 사람의 고통을 자극적으로 소비하지 않는다.

## 10. 파일 관리

- 경로: `archive/YYYY-MM-DD/assets/`
- 참조: `./assets/...`
- 불필요한 원본·중간 생성본·중복 파일은 커밋하지 않는다.
- SVG 파일은 회차 assets에 두지 않는다.
- 같은 SHA 또는 사실상 같은 이미지를 두 기사에 사용하지 않는다.

## 11. 접근성

의미 있는 이미지에는 기사 의미를 설명하는 간결한 대체 텍스트를 제공한다. `멋진 이미지`, `AI 이미지`처럼 정보가 없는 문구를 쓰지 않는다.

## 12. 발행 전 체크

- [ ] 실제 이미지 생성 모델로 만든 결과인가
- [ ] 프로그램 도형이나 벡터를 래스터화한 대체물이 아닌가
- [ ] 권장 해상도와 압축 품질을 충족하는가
- [ ] 실제로 열어 육안 검사했는가
- [ ] 카메라 공간감과 자연스러운 재질이 있는가
- [ ] 글자·숫자·로고·워터마크가 없는가
- [ ] 얼굴·손·장비에 생성 오류가 없는가
- [ ] 기사 또는 서사의 핵심과 직접 연결되는가
- [ ] 데스크톱과 모바일 크롭을 확인했는가
- [ ] 대체 텍스트와 필요한 캡션이 있는가

하나라도 확인하지 못하면 발행하지 않는다.
