## Issue 02 초안 — 2026.07.27–08.02

### 상태

- 2026년 8월 6일 발행 시도
- 품질 검수 실패
- `issues.json`과 `latest.json`에서 제거
- 파일은 삭제하고 이전 상태는 Git 커밋 이력으로만 보존
- 동일 회차는 처음부터 다시 제작

### 실패 원인

1. Cover Story 외 일반 기사가 Politics와 Tech 두 편뿐이어서 Economy와 Society가 누락됐다.
2. DEEP DIVE가 Cover Story와 같은 AI 투자 불확실성 → 반도체 재평가 → 지수 집중의 인과를 반복했다.
3. LIFE SCENE이 외부 제도 문제보다 개인 투자자의 위험관리 교훈으로 귀결됐다.
4. EDITOR'S PICK이 기사별 한 문단 요약 뒤 공통 교훈을 붙이는 두 번째 Contents가 됐다.
5. 주요 이미지가 7~15KB 수준의 저디테일 WebP였으며 래스터 형식만 통과하고 실제 생성 품질 검수가 없었다.
6. 모든 기사가 `제목 → 이미지 → 소제목 네 개 → 출처 칩` 구조를 반복해 긴 블로그 문서처럼 보였다.
7. 실제 브라우저 화면과 제1호 대비 검수 없이 발행 목록을 갱신했다.

### 반영된 수정

- `editorial/ISSUE_QUALITY_GATE.md` 신설
- Cover Story + Economy + Politics + Society + Tech 기본 구성 잠금
- DEEP DIVE 새 주장 3개·새 출처 2개·심화 차이 메모 의무화
- LIFE SCENE에서 개인 투자·소비·자기관리 조언형 주제 금지
- EDITOR'S PICK 기사별 요약 구조 금지
- 실제 이미지 생성 모델 사용과 해상도·용량 경고선·육안 검사 의무화
- 최소 세 가지 기사 레이아웃 리듬 의무화
- 1440px·1366px·1024px·390px 실제 화면 검수 의무화
- 모든 품질 게이트 통과 전 `issues.json`과 `latest.json` 갱신 금지
