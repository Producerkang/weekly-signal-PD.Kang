## Issue 01 — 2026.07.20–07.26

### 발행 경로

- `archive/2026-07-20/`

### 최종 구성

- Cover Story: 샌프란시스코 AI 선언의 구성과 발표·MOU·계약·가동 구분
- Economy: 강제노동 대응을 이유로 한 미국 Section 301 관세의 구조
- Economy / Macro: GDP와 GDI의 정의와 2분기 수치 차이
- Politics: 정부포상 198점 취소의 대상·절차·후속 기록
- Society: 5극3특 의료망의 정의와 대·중·소 진료권 구조
- Tech: 개인정보 제재·사전예방·데이터 활용 정책의 구성
- LIFE SCENE: 지역 응급의료의 수용·전원 공백
- Document Reportage: 제품·기록·환자·삭제 요청의 절차와 책임 이동
- DATA: 핵심 수치 6개와 수치 상태 설명
- WATCH: 후속 문서 6개
- SOURCES: 사용한 공식 1차 자료

### 편집 확인 사항

- 회차의 HTML은 `index.html` 하나로 완결했습니다.
- 이미지는 회차 내부 `assets/`에 분리했습니다.
- 반복형 검증 카드와 포괄적인 후속 기록 카드를 제거했습니다.
- 모든 르포의 후속 카드를 `확인된 조치 / 아직 확인할 것` 두 개로 정리했습니다.
- 개인정보 제목의 `6,804억 원`을 줄바꿈되지 않는 단위로 묶었습니다.
- 개인정보 숫자 카드의 텍스트 대비를 강화했습니다.
- DATA를 2열 6개 카드로 축소하고 수치 정의를 짧게 정리했습니다.
- WATCH에 상태·발표 주체·확인 문서·판단 기준·공식 링크를 넣었습니다.
- SOURCES에는 실제 사용한 1차 자료만 남겼습니다.
- 반복 수치를 재진술하던 기사 우측 카드를 제거하고 본문 폭을 통일했습니다.
- 2026년 7월 31일 개정에서 모든 섹션 기사를 정의·구조 설명 중심으로 전면 재작성했습니다.
- 섹션 기사는 생소한 공식 용어를 처음 보는 독자를 기준으로 작성하고, 분석과 개선 요구를 후반부로 이동했습니다.
- 르포는 제도 설명을 반복하지 않고 문서·조직·시간과 책임 이동을 맡도록 역할을 분리했습니다.
- 근거를 다시 확인하지 못한 `2029년 책임의료기관 72곳` 수치는 개정 원고에서 제거했습니다.
- 일반 섹션 기사 제목을 핵심 명제 중심으로 압축하고 Cover 외 수동 줄바꿈을 제거하는 방향으로 개정했습니다.
- 제목 크기를 한 단계 낮추고 `word-break: keep-all`을 적용해 한국어 제목의 과도한 조기 줄바꿈을 줄였습니다.
- Cover는 이미지 구도를 위해 의도적 줄바꿈을 유지하되 제목 자체는 짧게 줄였습니다.
- Opening에서 내부 서술 원칙 설명을 제거하고 `EDITOR'S PICK` 형식의 실제 편집 콘텐츠로 교체했습니다.
- 이후 Editor's Pick을 기사 3개 요약에서 한 단계 확장해, 이번 호 전체의 결론인 `발표보다 실제 의무와 책임으로 바뀌는 지점이 중요하다`를 먼저 제시하고 AI·지역의료·무역 기사를 그 결론의 근거로 연결했습니다.
- Editor's Pick의 마지막에는 `무엇이 발표됐는가 / 무엇이 확정됐는가 / 누가 실행 책임을 지는가`라는 독해 질문을 남기도록 수정했습니다.
- 2026년 7월 31일 1회차의 런타임 후처리 CSS·JS를 현재 최종 상태에 병합해 `archive/2026-07-20/index.html` 단일 보존본으로 평탄화했습니다.
- 이후 회차 수정은 별도 패치 파일을 누적하지 않고 해당 회차의 `index.html` 자체를 직접 갱신하며, 이전 상태는 Git 이력으로만 보존합니다.
- 평탄화 후 실제 적용값이 그대로 드러나 Cover 행간 2.50이 과도하게 벌어진 것을 확인해 최종 기준을 1.60으로 조정했습니다.

### 다음 회차 적용 규칙

1. 작업 시작 시 `editorial/SECTION_AND_REPORTAGE_STANDARD.md`와 `editorial/HEADLINE_AND_OPENING_STANDARD.md`를 반드시 읽습니다.
2. 새 정책명·산업 용어·법률명은 독자가 이미 안다고 가정하지 않습니다.
3. 제목 또는 첫 세 문단에서 핵심 용어의 정의, 대상과 범위를 설명합니다.
4. 섹션 기사 전반부는 사건·정의·구조·기관별 역할·일정·재정·확정/미정 상태를 중심으로 씁니다.
5. 영향·문제점·반론·평가 기준은 설명 뒤에 배치합니다.
6. 공식 용어는 정확히 유지하되 보도자료의 문장과 배열을 복사하지 않습니다.
7. 르포는 사람·조직·문서·데이터·시간의 경로를 맡고 섹션 기사와 같은 설명·결론을 반복하지 않습니다.
8. 본문에 이미 나온 대표 수치를 크게 반복하는 장식성 카드는 만들지 않습니다.
9. 일반 기사·르포 제목은 데스크톱에서 1–2행을 기본으로 하고 3행 이상이면 제목 문장을 먼저 줄입니다.
10. 카드 제목은 1행을 권장하고 최대 2행으로 제한합니다.
11. Cover 외 일반 표제에는 수동 `<br>`을 쓰지 않습니다. 한국어 표제는 자연스러운 폭에서 줄바꿈하고 단어 내부의 어색한 절단을 피합니다.
12. Editor's Pick은 기사 요약 목록이 아니라 해당 호 전체를 취재한 뒤 발견한 한 가지 편집적 결론·질문·긴장을 먼저 제시하고, 이를 실제로 뒷받침하는 기사 2–4개를 근거로 연결합니다. 결론을 미리 정하지 않으며 공통 주제가 약하면 억지로 모든 분야를 하나로 묶지 않습니다.
13. 이전 WATCH 항목을 `확인됨 / 미발표 / 일정 변경 / 종료`로 갱신합니다.
14. 1440px·1366px·1024px·390px 화면에서 제목 줄 수, 고아줄, 글자 크기, 본문 폭, 대비와 가로 스크롤을 확인합니다.
15. `issues.json`에 새 회차를 추가한 뒤 `latest.json`을 마지막에 갱신합니다.
