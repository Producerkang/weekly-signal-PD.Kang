## Issue 02 — 2026.07.27–08.02

- 발행 경로: `archive/2026-07-27/`
- 최초 발행일: 2026년 8월 6일
- 누적 교정일: 2026년 8월 6일
- 현재 제목: `발표 이후, 실제로 작동하는가`
- 상태: 1차 누적 교정 반영

### 초판 실패

- HTML이 약 19KB의 축소 셸에 가까웠다.
- 7개 주요 이미지가 동일한 4.9KB 파일이었고 CSS 필터로 차이를 위장했다.
- Economy와 Politics가 폭염 Cover Story를 분야명만 바꿔 반복했다.
- Society와 Tech가 공식 발표를 두세 문단으로 요약하는 데 그쳤다.
- DEEP DIVE가 독립 질문·새 주장·새 근거 없이 체크리스트형으로 끝났다.
- 모든 기사 지면이 제목·이미지·짧은 본문의 같은 패턴을 반복했다.

### 1차 누적 교정 구성

- Cover Story: 폭염 ‘심각’ 경보가 기관별 운영체계를 어떻게 바꾸는가
- DEEP DIVE: 체감온도 33도, 2시간, 20분 휴식규칙의 측정·기록·비용·책임
- Economy: 석유 최고 공급가격의 정의, 비용 부담과 소비자가격 전달경로
- Politics: 한·브라질 정상회담 MOU와 한·메르코수르 협상의 단계 구분
- Society: 소아 야간·휴일 진료의 검색·전화·이동·접수·약국·전원 경로
- Tech: AMD 협력에서 소프트웨어 이식, 이기종 운영과 전환비용
- LIFE SCENE: 야간 소아진료 이용 중 시간·이동·정보·돌봄 공백
- EDITOR'S PICK: 기관 수보다 실제 이용 가능한 시간이 중요하다는 판단 변화
- WATCH: 각 이슈에서 다음 판단을 바꿀 후속 문서와 운영기록

### 적용한 교정 원칙

- 호의 통일성은 동일 주제 반복이 아니라 동일한 편집 관점에서 만든다.
- 분야별 일반 기사는 서로 다른 사건·핵심 질문·1차 자료를 가져야 한다.
- DEEP DIVE는 일반 기사와 다른 질문, 새 주장과 새 출처를 제공한다.
- 지면은 응답 사슬, 규칙 표, 가격 보드, 상태 사다리, 서비스 여정과 기술 스택처럼 내용 구조에 맞춰 달리 설계한다.
- 동일 이미지 복제와 CSS 필터 위장은 영구 금지한다.

### 남은 이미지 과제

동일 저용량 파일 복제는 제거했다. 다만 첫 교정에서는 즉시 구조를 정상화하기 위해 기존 발행 래스터 자산 일부를 임시 재배치했다. 이는 최종 합격 이미지 사례가 아니다. Issue 03부터는 회차별 신규 생성 이미지의 로컬 저장과 육안 검수를 발행 전제조건으로 적용한다.
