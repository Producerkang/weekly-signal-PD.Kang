# Issue 02 지면 지도

## 고정 셸

Cover → Contents → LIFE SCENE → Editor's Pick → Cover Story → Economy → Politics → Society → Tech → Data → Watch → Sources 순서를 유지한다.

상단 내비게이션, 진행 바, 중앙 기준축, 장문 본문 단일 열, 브랜드 색상 역할과 Document Reportage 무이미지 원칙을 유지한다.

## 승인 모듈

각 꼭지는 내용에 따라 다음 모듈 중 필요한 것만 사용한다.

- `text-led`
- `image-led-opening`
- `split-opening`
- `evidence-grid`
- `metric-board`
- `process-timeline`
- `document-reportage`

모든 기사에 같은 카드 구조를 반복하지 않으며 본문을 다시 적는 장식성 카드를 만들지 않는다.

## 이미지

원고와 지면 설계가 끝난 뒤 Cover, LIFE SCENE, Cover Story, Economy, Politics, Society, Tech 이미지를 각각 제작한다. Document Reportage에는 이미지를 넣지 않는다.

구체적인 모듈과 이미지 비율은 최종 꼭지 선정 뒤 각 꼭지의 `layout.md`에서 확정한다.
