# Issue 02 자료 지도

현재 문서는 후보 검토용이며, 기사 원고가 아니다.

## 기사별 근거 역할

각 후보는 다음 다섯 역할을 확인한다.

1. 사건: 결정·발표·판결·공시 원문
2. 수치: 규모·추세·비교 자료
3. 절차: 집행·계약·행정·운영 구조
4. 영향: 비용·권한·시간·접근성 변화
5. 반론: 예외·제약·불확실성 또는 다른 관점

## 검토 원칙

- 대표 기사마다 독립된 1차 자료를 원칙적으로 3개 이상 확보한다.
- 목록 페이지가 아니라 개별 문서 고정 주소를 기록한다.
- 발표·계획·MOU·계약·집행·성과를 구분한다.
- 재확인할 수 없는 수치와 단일 보도자료만으로 구성된 후보는 제외한다.
- 실제 사용한 원문만 각 꼭지의 `sources.md`로 이동한다.

## 현재 상태

후보별 원문을 처음부터 다시 수집해야 한다. 기존 철회본의 출처 목록과 수치는 검증 완료 자료로 간주하지 않는다.
