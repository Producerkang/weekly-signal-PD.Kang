# Document Reportage Layout

- 모듈: `document-reportage`, `process-timeline`
- 이미지: 없음
- 배경: Deep Navy와 warm gray를 교차해 대표 기사와 전환

## 문서 경로
피해구제 신청 → 지급정지 통지 → 연계정보 분석·추가 조치 → 채권소멸 공고 → 이의·신청 기간 → 환급액 결정 → 금융회사 지급.

각 단계에 문서명, 책임기관, 다음 이동 조건을 둔다. 실제 개인 계좌번호·이름·금액은 사용하지 않는다.

후단 카드는 `확인된 조치`, `아직 확인할 것` 두 개만 사용한다.
