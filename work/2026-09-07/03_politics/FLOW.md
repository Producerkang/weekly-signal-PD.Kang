# POLITICS FLOW

STATUS: COMPLETE

## 중심 질문

지방체육 보조금 실태조사에서 부실·부정 의심 사례가 드러난 뒤, 권익위의 ‘환수 권고’는 어떤 절차를 거쳐 실제 반환·제재·수사로 바뀌는가?

## 설명 순서

### 1. 조사 결과가 왜 끝이 아닌가
- 3년간 31,578개 사업·1조 5,313억 원이라는 전체 규모와 12개 지방정부 집중조사를 먼저 설명한다.
- 최소 200억 원은 관리 부실 사업에 투입된 보조금 규모이며 확정 환수액이 아님을 분명히 한다.

### 2. 권익위는 적발·통보·권고, 처분은 지방정부
- 권익위의 조사·시정권고와 지방정부의 법적 처분 역할을 분리한다.
- 조사 결과가 개별 보조사업의 증빙 검토와 처분으로 좁혀지는 과정을 보여준다.

### 3. 환수는 ‘돈을 돌려받는’ 행정절차
- 교부결정 취소와 반환명령의 관계를 설명한다.
- 실제 반환액은 사업별 사실확인 뒤 정해진다는 점을 둔다.

### 4. 제재부가금은 환수와 별개로 추가된다
- 지방보조금법상 최대 5배 구조를 설명하되 모든 사건에 5배가 자동 적용된다고 쓰지 않는다.
- 시행령 별표의 위반유형별 부과율과 서면 통지·불복 절차를 설명한다.

### 5. 행정상 책임과 형사책임은 다른 선로다
- 횡령·배임 의심은 수사의뢰 이후 수사기관 판단으로 넘어간다.
- 환수·제재부가금과 형사처벌을 하나의 제재로 합쳐 쓰지 않는다.

### 6. 다음에 볼 것은 ‘적발 규모’보다 집행 결과다
- 지방정부별 최종 환수액, 제재부가금, 수사 결과, 수익금 정산규정 개선을 후속 지표로 제시한다.

## 분석 전환 지점

반환·제재·수사라는 세 절차를 설명한 뒤, 발표 규모와 실제 책임 확정 사이의 간격이 왜 행정 책임성의 핵심인지 분석한다.

## 반복 방지

- Cover Story의 전력계통·수요이동·가격신호를 사용하지 않는다.
- Economy의 수출·반도체·내수 확산 논리를 사용하지 않는다.
- `발표와 시행은 다르다`는 추상적 대조를 반복하지 않고 조사권·처분권·수사권의 구체적 분담을 중심축으로 삼는다.
