# Economy FLOW

STATUS: COMPLETE

## 중심 질문

하루 1조 원대의 전자지급서비스가 움직이는 시장에서 이용규모 증가와 실제 정산·자금보호 구조는 어떻게 연결되는가.

## 설명 순서

### 1. 이번 통계의 네 숫자
PG 1조 7,234억 원, 선불 1조 5,535억 원, 간편지급 1조 2,264억 원, 간편송금 1조 1,728억 원의 일평균 이용금액과 전년동기 대비 증가율을 제시한다.

### 2. PG가 하는 일
구매자와 판매자 사이에서 결제정보와 정산을 대행·매개하는 PG의 역할을 먼저 닫는다. PG 이용금액을 소비 총액으로 읽지 않는 이유도 여기에서 설명한다.

### 3. 선불과 간편 서비스의 다른 축
선불은 미리 충전한 가치라는 자금 성격, 간편지급·송금은 인증·이용방식이라는 성격을 설명해 통계 숫자를 단순 합산하지 않는다.

### 4. 성장률이 보여주는 변화
PG +12.6%, 선불 +21.9%, 간편지급 +16.8%, 간편송금 +19.8%를 통해 전자적 결제·송금 인프라를 거치는 자금 규모가 확대되고 있음을 설명한다.

### 5. 규모가 커질수록 정산이 중요해지는 이유
결제 순간과 판매자가 실제 대금을 받는 순간 사이에 PG가 보유·관리하는 정산자금이 생긴다. 시장 성장과 자금보호 문제를 연결한다.

### 6. 다음 제도 변화
PG 정산자금 전액 외부관리 의무가 2026년 12월경 시행 예정이라는 현재 상태를 설명하고, 향후 확인할 것은 시행령·가이드라인과 실제 정산 관행 변화라고 정리한다.

## 분석 전환

1~4는 통계와 서비스 구조, 5~6은 비용·위험·규제의 전달경로다.
