# SOCIETY FLOW

STATUS: COMPLETE

## 중심 질문

학교 200m 안에서 집회가 신고되면, 새 교육환경법은 학교장과 경찰을 어떤 순서로 연결하고 무엇을 실제 제한하게 되는가.

## 설명 단위

1. 8월 20일 본회의 통과와 공포 후 3개월 시행 예정.
2. 교육환경보호구역 200m의 기존 의미와 범위.
3. 새 절차: 경찰 신고 접수 → 학교장 통보 → 학습권 침해 우려 판단 → 경찰에 조치 요청.
4. 학교장이 직접 집회를 금지하는 구조가 아니라는 권한 구분.
5. 차별·모욕·비하 목적, 심각한 소음, 반복적 욕설·폭언 등 구체적 판단 사유.
6. 집회 자유와 학습권이 충돌할 때 필요한 비례성·기록·사후심사.
7. 시행 뒤 확인할 지표: 통보·요청·금지·제한 사례와 법원 판단.

## 분석 전환

4번까지 제도의 작동을 설명하고 5번부터 제한 기준의 구체성과 기본권 균형을 분석한다.

## FLOW 점검

- `학교 앞 시위 금지`라는 과장된 프레임을 피함.
- 공간 정의 → 신고 → 판단 → 조치라는 실제 절차를 따라감.
- Politics의 범죄수익 환수와 기관·질문이 독립적임.
