# Society FLOW

STATUS: FLOW_COMPLETE

## 중심 질문

같은 청소년을 여러 해 따라가는 패널자료는 매년 다른 학생을 조사하는 횡단면 통계와 무엇이 다르고, 정책 판단에 어떤 새 질문을 가능하게 하는가?

## 설명 단위

### 1. 8월 12일, 데이터가 ‘연구 대상’으로 본격 이동했다
- 제1회 원시자료 활용 경진대회·학술행사를 사건의 시작점으로 둔다.
- 조사 자체가 새로 시작된 것이 아니라 축적 자료의 활용 단계라는 점을 분명히 한다.

### 2. 패널조사는 같은 사람의 시간을 따라간다
- 2019년 초6 기반조사부터 매년 같은 코호트를 추적하는 구조를 설명한다.
- 학생·학부모·학교담당자 자료가 함께 있다는 점을 연결한다.

### 3. 매년 전국 수준을 보는 조사와 역할이 다르다
- 청소년건강행태조사의 800개 학교·약 6만 명 횡단면 구조를 소개한다.
- 횡단면은 ‘그해 수준’, 패널은 ‘같은 사람의 변화’를 보는 데 강하다는 역할 차이를 설명한다.

### 4. 같은 사람을 보면 새로 물을 수 있는 질문이 생긴다
- 위험요인의 선행 여부
- 위험 지속과 회복 경로
- 가정·학교환경 변화와 개인 건강 변화의 동행 여부
- 인과를 단정하지 않고 시간 순서 관찰의 장점을 설명한다.

### 5. 종단자료도 자동으로 정답을 주지는 않는다
- 패널 탈락, 응답편향, 변수 정의, 공개연도 차이를 설명한다.
- 분석 설계와 가중치·보정이 중요하다는 분석으로 전환한다.

### 6. 다음 단계는 ‘더 오래 추적하는 것’과 ‘정책에 연결하는 것’이다
- 고3 이후 성인 초기까지 추적 설계를 확인한다.
- 원시자료 추가 공개, 유지율, 연구 결과의 정책 반영을 후속 판단 기준으로 제시한다.

## 수치·사실 배치

- 2019~2023 원시자료 공개: 2단위
- 초6 → 중1 → 중2 → 중3 → 고1 → 고2 → 고3 → 만19~21세: 2단위
- 청소년건강행태조사 800개 학교, 2025년 57,682명 대상·54,170명 참여: 3단위

## 분석 전환 지점

4단위에서 종단자료의 장점을 설명한 뒤 5단위부터 분석 한계를 다룬다.

## FLOW 점검

- 행사 → 조사구조 → 비교조사 → 가능한 질문 → 한계 → 후속과제 순으로 이어진다.
- 단순 데이터 공개 홍보가 아니라 조사 설계가 정책 질문을 어떻게 바꾸는지 설명한다.
- Issue 03 Society의 복지위기 발굴과 주제·자료·작동 구조가 겹치지 않는다.
