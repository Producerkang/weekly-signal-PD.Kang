# ISSUE 04 · ECONOMY · FLOW

STATUS: COMPLETE

## 중심 질문

2027년 적용 최저임금안의 시간급 10,700원은 표준 월급과 사업장 비용으로 어떤 경로를 거쳐 전달되며, 무엇을 같은 숫자로 보면 안 되는가?

## 독자 이해 순서

### 1. 사건 — 10,700원은 어떤 상태의 숫자인가
- 최저임금위원회가 2027년 적용안으로 시간급 10,700원을 의결했다.
- 고용노동부가 7월 16일 최저임금안을 고시했다.
- 최저임금안 고시와 장관의 최종 결정·고시를 구분한다.

### 2. 변화 — 380원이 월 단위에서 얼마가 되는가
- 2026년 시간급 10,320원 → 2027년 적용안 10,700원.
- +380원, +3.7%.
- 주 40시간·월 209시간 환산액 2,236,300원.
- 같은 기준의 2026년 월 환산액 2,156,880원.
- 단순 월 차이 79,420원.

숫자를 먼저 명확히 계산한 뒤 실제 비용과의 차이를 설명한다.

### 3. 209시간 — 왜 월 환산액이 실제 월급과 같지 않은가
- 209시간은 표준 환산 조건이다.
- 개별 근로자의 실제 유급시간은 다를 수 있다.
- 월 환산액은 실수령액도 아니다.
- 독자가 시간급 → 표준 월 환산 → 실제 급여를 순서대로 구분하게 한다.

### 4. 사업장 — 시간급이 총인건비로 가는 사이에 무엇이 붙는가
- 적용 유급시간.
- 주휴와 가산임금.
- 최저임금 산입 임금항목.
- 사회보험 등 사용자 부담.
- 인원과 근로시간 구성.

`최저임금 3.7% 인상 = 모든 기업 인건비 3.7% 증가`라는 단순 등식을 만들지 않는다.

### 5. 노동시장 — 영향근로자가 왜 66만명과 297만8천명으로 다르게 보이는가
- 고용형태별 근로실태조사와 경제활동인구 부가조사는 모집단·방법이 다르다.
- 각각 영향률 3.8%, 13.3%.
- 두 수치를 충돌하는 추정으로 표현하지 않고 조사 기준 차이로 설명한다.

### 6. 분석 — 기업과 근로자가 실제로 마주하는 선택
- 저임금 근로자의 임금 하한 상승.
- 사업장의 임금예산·가격·근로시간·인력구성·생산성 조정 가능성.
- 업종별 인건비 비중과 수요가 다르므로 단일 결과를 예언하지 않는다.
- 10,700원 자체보다 시행 후 고용·시간·가격·생산성 데이터를 봐야 한다.

### 7. 다음 증거 — 결정 이후 무엇을 확인해야 하는가
- 장관의 최종 결정·고시 원문.
- 실제 적용 범위와 기간.
- 2027년 시행 후 업종별 임금분포·고용·근로시간.
- 2026년 하반기 제도개선 추진단의 실제 검토 결과.

## 설명 → 분석 전환점

`시간급 → 209시간 환산 → 실제 사업장 비용 구성`까지가 작동 설명이다. 그 뒤부터 기업이 어떤 방식으로 비용을 흡수하거나 조정하는지, 실제 노동시장 결과를 어떤 지표로 판단할지를 분석한다.

## 핵심 수치

- 2026년: 10,320원
- 2027년 적용안: 10,700원
- 차이: 380원
- 인상률: 3.7%
- 209시간 환산: 2,236,300원
- 2026년 209시간 환산: 2,156,880원
- 표준 월 차이: 79,420원
- 영향근로자 추정: 66만명(3.8%) / 297만8천명(13.3%)

## 금지할 전개

- `10,700원이 최종 확정됐다`고 1차 자료 확인 범위를 넘어 단정하지 않는다.
- 월 환산액을 모든 근로자의 실제 월급이나 실수령액으로 쓰지 않는다.
- 3.7%를 모든 기업의 총인건비 증가율로 쓰지 않는다.
- 영향근로자 두 추정치 중 하나를 오류로 취급하지 않는다.
- 인상률 하나만으로 고용 감소·물가 상승을 예언하지 않는다.
