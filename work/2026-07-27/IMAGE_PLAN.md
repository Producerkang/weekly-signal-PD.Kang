## 1. 실행 원칙

월요일 08:00은 지면 설계와 이미지 제작을 담당하는 하나의 예약 작업 턴이다. 이 턴에서는 아래 슬롯을 순서대로 끝까지 처리한다.

```text
1 SLOT = 1 SCENE = 1 IMAGE
```

- 한 번의 생성 요청에는 한 슬롯만 포함한다.
- 한 슬롯 생성 뒤 OUTPUT CONTRACT와 육안 품질을 판정하고 상태를 기록한 뒤 다음 슬롯로 이동한다.
- 첫 이미지 한 장이 나왔다는 이유로 턴을 종료하지 않는다.
- 연락시트·스토리보드·무드보드·이미지 팩을 만들지 않는다.
- 이미 통과한 슬롯은 다른 슬롯 실패 때문에 다시 생성하지 않는다.
- 한 슬롯의 기본 최대 유효 시도는 3회다.
- 3회의 유효 시도에도 통과하지 못하면 `BLOCKED`로 기록하고 다음 슬롯로 이동한다.
- `OUTPUT_CONTRACT` 자체를 위반해 사진 생성 단계에 진입하지 못한 출력은 유효 이미지 시도 횟수에 포함하지 않는다.
- 최종 채택본만 `archive/2026-07-27/assets/`에 저장한다.
- 기존 `archive/2026-07-27/assets/`에 존재하는 과거·재사용 blob은 제2호 최종 자산으로 인정하지 않는다.

## 14. 판정 코드

- `READY`: 생성 대기
- `ACCEPTED`: 이미지 자체는 품질 게이트 통과
- `SAVED`: 최종 자산 경로에 저장 완료

- `BLOCKED`: 유효 시도 3회 실패 또는 실행 불가 사유로 더 이상 처리 불가

실패 코드는 필요한 경우 다음처럼 기록한다.

- `SUBJECT_MISMATCH`
- `HUMAN_PRESENT_POLITICS`

- `TEXT_LOGO`
- `COMPOSITION`
- `RESOLUTION`
- `SAVE_UNAVAILABLE`
