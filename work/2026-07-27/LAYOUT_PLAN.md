- 별도 DATA를 만들면 기사 본문에 이미 있는 수치를 다시 요약할 가능성이 크다.

### WATCH — OMIT

## 4. 프런트 지면

### 4.1 Cover

- 역할: 한 호의 대표 상태를 한눈에 열고 Cover Story로 연결한다.
- 이미지: REQUIRED — `cover.webp`
- 구도: 전체 폭 배경 이미지, 데스크톱에서 약 72~82vh 범위의 강한 첫 화면.
- 제목 안전영역: 좌측 상단~중단 또는 좌측 중앙에 넓은 저정보 영역 확보.
- 이미지 장면: 극심한 한낮 더위가 체감되는 한국 도시의 실제 생활 공간. 완성 잡지 표지 그래픽은 금지.
- Cover Story 본문 이미지와 동일한 원본·거리·구도를 사용하지 않는다.
- 모바일: 세로 크롭 시 핵심 장면이 유지되도록 `object-position` 우선 조정.

### 4.2 Contents

- 이미지 없음.
- 2열 또는 3열의 얇은 편집 그리드로 실제 DOM 순서만 노출.
- 섹션 라벨·기사 제목·짧은 한 줄 덱만 사용하며 내부 스크롤은 만들지 않는다.
- 1024px 이하 2열, 390px 1열.

### 4.3 LIFE SCENE

- 독립 프런트 스프레드.
- 이미지: REQUIRED — `life-scene.webp`
- 비율: **4:5 세로형 확정**.
- 데스크톱: 이미지 42~46% + 제목·첫 서사 54~58%의 비대칭 2열 도입.
- 본문 진입 뒤에는 좁은 단일 열 서사로 전환해 소제목 없이 흐르게 한다.
- 중간 정책 카드·수치 패널 금지.
- 마지막 `SCENARIO NOTE`만 별도 톤의 얇은 경계 박스로 처리.
- 1024px 이하: 이미지 위 / 텍스트 아래 1열.
- 390px: 이미지 전체 폭, 과도한 세로 점유를 막기 위해 최대 높이 제한 없이 자연 비율 유지.

### 4.4 PROLOGUE

- 별도 생성 이미지 없음.
- 텍스트 중심 편집 스프레드.
- 첫 문단의 여러 숫자와 사건을 카드로 분해하지 않고 큰 본문 타이포그래피와 여백으로 처리.
- 중간의 `1,784원`, `1,461곳`, `40분`, `오후 3시` 같은 숫자는 장식적 대형 숫자로 반복하지 않는다.
- LIFE SCENE의 서사 호흡에서 본 기사 묶음으로 전환하는 브리지 역할에 집중.

## 5. 본 기사 지면 리듬

### 5.1 Cover Story — 폭염

- 이미지: REQUIRED — `cover-story.webp`
- 리듬: `이미지·텍스트 2열 도입 → 단일 열 본문 → 운영기록 체크포인트 모듈 → 단일 열 결론`.
- Cover와 다른 거리·장면을 사용한다.
- 정보 모듈: `evidence-grid` 3개 이하.
  - 취약계층 예찰·쉼터 운영
  - 야외·고위험 사업장 점검
  - 고령 농업인·지역 대응
- 숫자와 행동 기준은 실제 기사 문구에서만 가져오며 카드가 본문을 재요약하지 않게 한다.
- 1024px 이하 2열 도입을 1열로 전환.

### 5.2 Economy — 석유 최고가격

- 이미지: REQUIRED — `economy.webp`
- 리듬: `넓은 이미지 브레이크아웃 → 핵심 수치 밴드 → 단일 열 본문 → 공급가/판매가 비교표`.
- 핵심 수치 밴드:
  - 휘발유 1,784원
  - 경유 1,773원
  - 등유 1,380원
  - 적용기간 4주
- 비교표는 `정유사 공급가격 상한 / 실제 평균공급가격 / 주유소 평균판매가격`의 정의가 섞이지 않도록 열 제목에 단계를 명시한다.
- 표는 390px에서 가로 스크롤 대신 행 단위 스택 또는 CSS grid 재배열.

### 5.3 Politics — 한·브라질 정상회담 후속 경로

- 이미지: REQUIRED — `politics.webp`
- **Politics 이미지 완전 무인**.
- 리듬: `빈 회의공간 이미지 → 3경로 구조 다이어그램형 HTML → 단일 열 본문 → 기록 유형 3개 요약`.
- 3경로 구조는 그래픽 이미지가 아니라 HTML/CSS 조판으로 구성:
  1. 7개 MOU·MOC
  2. 경제·통상 위원회
  3. 한·메르코수르 무역협상
- 각각 `담당 주체 / 다음 문서·회의 / 효력 시점`만 짧게 비교.
- 실제 인물 사진·실루엣·반사 속 인물·화면 속 인물 금지.

### 5.4 DEEP DIVE · Politics — 한·메르코수르 발효 구조

- 별도 생성 이미지 없음.
- 일반 Politics 기사와 시각 언어를 분리한다.
- 리듬: `좁은 장문 도입 → 단계 타임라인 → 싱가포르 FTA 사례 비교 → 발효조항 체크포인트`.
- 핵심 모듈: 실제 절차를 보여주는 `timeline`.

```text
국내 의견·민감성 정리
→ 메르코수르 공동 협상안
→ 협상 타결
→ 서명
→ 국가별 국내 승인·비준
→ 협정문이 정한 발효
→ 품목별 관세철폐 일정
```

- 싱가포르 FTA 사례는 국가별 발효일 차이를 `comparison-table`로 처리해 본문과 다른 심화 질문을 시각적으로 드러낸다.
- Politics와 마찬가지로 별도 이미지가 필요해질 경우에도 완전 무인 원칙을 유지하지만, 이번 회차에서는 이미지 슬롯을 만들지 않는다.

### 5.5 Society — 방학 틈새돌봄

- 이미지: REQUIRED — `society.webp`
- 리듬: `이미지와 제목의 절제된 2열 도입 → 시간표 모듈 → 단일 열 본문 → 목표/첫 운영 수치 밴드`.
- 시간표 모듈:
  - 틈새돌봄센터 09:00–18:00
  - 점심돌봄센터 11:00–20:00
- 수치 밴드:
  - 최초 목표 2,500개소
  - 첫 운영 1,461개소
- LIFE SCENE과 같은 가족 서사를 반복하지 않고 정책의 운영시간·시설 규모에 집중.

### 5.6 Tech — 공공나노팹센터

- 이미지: REQUIRED — `tech.webp`
- 리듬: `와이드 클린룸/장비 이미지 → 법정 기능 4개 evidence-grid → 장비 이용 흐름 → 단일 열 결론`.
- 법정 기능 4개:
  - 공동활용
  - 전문인력 양성
  - 연구성과 실용화
  - 창업지원
- 이용 흐름은 HTML/CSS로 `장비 탐색 → 예약/신청 → 공정서비스 → 결과/다음 연구`를 간결하게 표현.
- 가짜 장비 UI, 대형 텍스트, 허구 로고를 이미지 안에 만들지 않는다.
