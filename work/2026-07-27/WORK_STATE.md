## 적용 구조

각 일반 기사는 다음 순서로 하나씩 완성한다.

`VERIFY → NARRATIVE → ANALYSIS → STYLE PASS → HEADLINE & DECK → ARTICLE REVIEW → COMPLETE`

- `VERIFY.md`: 내부 검증 전용
- `ARTICLE.md`: 독자용 최종 기사 전용
- 두 파일의 언어와 역할을 섞지 않는다.
- 현재 기사 COMPLETE 전에는 다음 일반 기사 본문을 작성하지 않는다.
