# Image Runs

이 디렉터리는 회차 이미지 생성 결과를 Git에 영구 보존하는 작업 자산 영역이다.

규칙:

- 생성된 모든 이미지 결과를 합격 여부와 관계없이 저장한다.
- 슬롯별 디렉터리를 사용한다: `01_cover/`, `02_cover_story/` 등.
- 파일명은 `attempt-01.<ext>`, `attempt-02.<ext>` 형식으로 기록한다.
- 각 이미지 옆에 같은 번호의 `attempt-01.json` sidecar를 둔다.
- `CONTEXT_FAILURE`·품질 실패 결과도 삭제하지 않고 진단 자료로 남긴다.
- 유효 사진 시도 횟수와 파일 보존 여부는 별개다.
- `archive/`에는 최종 ACCEPTED 이미지의 발행용 변환본만 복사한다.
- 이미지 반환 뒤 Git 저장이 실패하면 다음 슬롯으로 진행하지 않는다.

이 경로는 공개 GitHub 저장소의 `main`에 존재하므로 비공개 정보나 인증정보를 sidecar에 기록하지 않는다.
