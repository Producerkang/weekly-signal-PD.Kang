# TECH FLOW MAP

상태: COMPLETE

## 중심 질문

한국나노기술원과 나노종합기술원이 첫 공공나노팹센터로 지정되면서, 기존 나노·반도체 연구시설의 공동활용을 지원하고 이용성과를 관리하는 국가 인프라 구조는 어떻게 바뀌는가?

## 설명 단위 1 — 나노팹 공동활용은 왜 연구개발의 기반이 되는가

**답할 질문**
대학·중소기업·연구팀이 나노·반도체 장비를 공동으로 이용해야 하는 이유는 무엇인가?

**넣을 정보**
- 나노팹의 기능: 노광·증착·식각·분석 등 공정과 측정
- 고가 장비, 청정시설, 유지비, 전문 운용인력
- 개별 연구팀이 같은 수준의 인프라를 각각 갖추기 어려운 구조
- 외부 연구자와 기업이 공공 나노팹의 장비·공정서비스를 이용하는 기존 공동활용 방식

**직전에서 받는 것**
7월 29일 공공나노팹센터 출범 사건.

**다음으로 넘기는 것**
공동활용이 이미 존재했다면 지정제도는 어떤 기능과 책임을 공식화했는가.

## 설명 단위 2 — 기존 두 기관에 국가 공동활용 거점의 법적 지위가 붙었다

**답할 질문**
공공나노팹센터 지정으로 어떤 기능이 법률상 명확해졌는가?

**넣을 정보**
- 한국나노기술원·나노종합기술원은 기존 나노팹 운영기관
- 2025년 법 개정, 2026년 3월 지정 지침, 5월 첫 지정, 7월 29일 출범
- 법정 기능: 산학연 공동활용 지원, 전문인력 양성, 연구성과 실용화, 창업지원
- 시행령의 산학연 공동연구·기업 기술지원·연구기반 구축 기능

**직전에서 받는 것**
공공 장비를 공동으로 이용해야 하는 구조.

**다음으로 넘기는 것**
공식 기능을 장기간 운영하려면 어떤 재정·시설 지원 수단이 필요한가.

## 설명 단위 3 — 지원 근거는 시설·장비와 장기 운영까지 이어진다

**답할 질문**
지정센터를 유지·확장하기 위해 법은 어떤 지원 수단을 마련했는가?

**넣을 정보**
- 정부가 시설·장비 구축·운영 경비 전부 또는 일부 출연 가능
- 지방자치단체의 공유재산·물품 사용허가·대부 특례
- 사용허가·대부 기간 최대 20년
- 실제 지원 규모는 각 연도 예산·사업계획·집행자료에서 구체화됨

**직전에서 받는 것**
공공나노팹센터의 공식 기능.

**다음으로 넘기는 것**
지원된 인프라를 연구자가 실제로 찾고 이용하는 접점은 어디인가.

## 설명 단위 4 — 공동활용은 검색·신청·공정서비스를 하나의 이용 경로로 잇는다

**답할 질문**
연구자와 기업은 여러 나노팹의 장비와 공정서비스를 어떤 경로로 이용하는가?

**넣을 정보**
- 두 기관이 기존부터 운영해 온 장비·공정서비스
- 법상 나노팹 통합정보시스템 구축·운영 근거
- 시행령의 시설·장비 정보 제공, 이용 신청·관리 통합서비스
- 모아팹 시설활용지원사업: 대학 연구자 이용료 일부 지원과 신청 접점
- 7월 29일 간담회에서 모아팹을 통한 나노 인프라 연계 논의
- 실제 이용에는 장비 조건·소재·예약 대기시간·전문인력 지원 범위가 함께 작용

**직전에서 받는 것**
시설과 장비를 운영할 지원 수단.

**다음으로 넘기는 것**
이용 경로가 실제 공동활용 성과로 이어졌는지 어떤 공식 기록으로 확인하는가.

## 설명 단위 5 — 연간 보고와 평가는 공동활용 성과를 남긴다

**답할 질문**
지정센터의 운영과 성과는 어떤 주기로 관리되는가?

**넣을 정보**
- 매년 1월 31일까지 전년도 운영실적·당해 사업계획 보고
- 과기정통부의 1년 단위 운영실적 평가 가능
- 공동활용·기술실증·사업화·인력양성은 운영 목표
- 성과 평가는 실제 이용·지원·실증·사업화 기록으로 구체화

**직전에서 받는 것**
연구자가 장비를 찾고 이용하는 실제 접점.

**다음으로 넘기는 것**
공공 인프라가 연구개발 속도를 높였는지 보여줄 실질 지표는 무엇인가.

## 설명 단위 6 — 성과는 접근시간과 처리 실적에서 드러난다

**답할 질문**
법적 지위의 변화가 연구현장의 변화로 이어졌는지는 어떤 지표로 판단할 수 있는가?

**넣을 정보**
- 외부 공동활용 건수와 이용자 구성
- 장비 가동률·예약 대기시간·공정서비스 처리기간
- 기업 기술지원·실증·사업화 연계
- 정부 출연예산과 실제 집행항목
- 모아팹 참여기관·장비·신청·연계 실적
- 2026년 운영실적과 2027년 사업계획

**직전에서 받는 것**
연간 보고·평가라는 책임 구조.

**마무리**
공공나노팹센터 제도의 핵심은 기존 고가 연구시설을 공동활용 기능, 지원 수단, 이용 경로, 성과평가가 이어지는 하나의 국가 인프라 체계로 운영하는 데 있다. 실제 변화는 연구자가 필요한 장비를 찾고 이용해 다음 연구 단계로 넘기는 시간과 지원실적에서 구체화된다.

## 분석 전환 지점

설명 단위 4까지는 공동활용 필요, 지정 기능, 지원 수단, 이용 경로를 설명한다. 설명 단위 5부터 운영 책임과 성과 판단 기준을 분석한다.

## COHERENCE 사전 점검

- ‘공동활용 필요 → 법정 기능 → 지원 수단 → 이용 경로 → 보고·평가 → 성과’ 순서로 한 축을 따라간다.
- 기존 기관과 새 지정제도의 관계를 각각 정의해 설명하고 반박형 서사를 만들지 않는다.
- 정부 출연 가능 근거와 실제 예산·집행 규모를 같은 상태로 쓰지 않는다.
- 모아팹은 여러 나노팹을 잇는 이용 접점으로 설명하고 지정센터 자체와 동일시하지 않는다.
- 마지막은 제도 명칭보다 연구자의 접근시간·처리기간·지원실적이라는 실질 성과로 닫는다.
